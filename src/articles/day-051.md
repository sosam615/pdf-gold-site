To edit a PDF resume quickly, open it in a PDF editor, press the Edit text tool, click the line you want to change, type the new wording and save a copy. In Gold PDF that is **E**, click, type, Ctrl+Shift+S, and the rest of the page stays exactly where it was.

## Quick steps
1. Open the resume with Ctrl+O and press **Save as** (Ctrl+Shift+S) straight away, for example "Resume-ACME-2026.pdf", so the master copy stays untouched.
2. Make a short list of what must change: contact details, job title, dates, a bullet point, a skill.
3. Press **E**. Dotted boxes appear around every line of text.
4. Click the line, change only the words that differ and press Enter.
5. Zoom to 150% and check that the line still fits inside the margins and nothing overlaps.
6. Save with Ctrl+S, reopen the file and search (Ctrl+F) for the old words to be sure none remain.
7. Select a line of text with the mouse to confirm it can still be selected and copied.

## What you can and cannot change in a PDF resume
A resume is designed to look the same on every screen, which is why people send it as a PDF. That also means the file is a fixed page, not a flowing document. Each line is stored as a positioned piece of text. There is no paragraph that wraps, no list that renumbers itself and no section that moves down when you add a bullet.

That gives you a clear rule of thumb:

| Change | Difficulty | Notes |
|---|---|---|
| Fix a typo or a wrong date | Very easy | Edit the line, same length |
| New phone number, email or city | Easy | Check the line still fits |
| Reword a bullet point | Easy | Keep it about the same length |
| Replace a job title or employer | Easy | Check column alignment if dates sit on the same line |
| Add a bullet to an existing role | Medium | Only works if there is blank space beneath it |
| Add a whole new job or section | Hard | The page will not reflow; edit the source file if you have it |
| Change fonts or layout across the page | Hard | Better done in the original design file |

If you need a bigger change, the honest answer is that the original Word, Google Docs or design file is the right place for it. For anything smaller, editing the PDF is much faster than rebuilding the page.

## How to fix a typo, a title or a date on a resume
These are the edits most people actually need, and they are the easiest. Press **E** and click the line. It opens with its current text, so you change only the characters that differ. For a single wrong word, select just that word instead of retyping the line, because the fewer characters you touch, the less can shift.

Pay attention to the way dates are written on your resume. If every role shows "Mar 2021 - Jun 2023", keep that style when you change one of them. A date written another way draws the eye, and recruiters read inconsistency as carelessness. For date-specific tips, see [how to change a date in a PDF](/articles/how-to-change-a-date-in-a-pdf/), and for plain spelling mistakes, [how to correct a typo in a PDF](/articles/how-to-correct-a-typo-in-a-pdf/).

Finally, proofread the whole page once after you finish. A resume is short enough that a slow read from top to bottom takes two minutes and catches the mistake you introduced while fixing another one.

## Updating contact details and links
Contact lines are the most common reason to open an old resume, and they are also where mistakes cost the most: a wrong digit in a phone number means a missed call. After you edit, read each number or address aloud and compare it with the source.

If your resume contains a clickable link, such as a portfolio or LinkedIn address, note that changing the visible text does not necessarily change where the link points. After you save, click the link in a normal PDF viewer and see where it goes. If it still opens the old address, replace the link as well, or use a plain-text address that a reader can copy.

Also search for the old details everywhere. Many resumes repeat an email in the header and again in the footer, or on a second page. Press Ctrl+F, type a piece of the old value and step through the results.

## Adding a line or a skill without breaking the layout
Sometimes you only need one more line, for example a certification or a new tool in a skills list. If there is empty space under the list, use the Text tool (**T**), click an empty spot, type the line and match the size and colour of the lines around it. Then drag it into alignment and check at 150% zoom.

If there is no space, you have two sensible choices. You can shorten something else on the page, for example merge two skills onto one line, or you can reduce the font size of a block slightly. Our guide to [changing the font size in a PDF](/articles/how-to-change-the-font-size-in-a-pdf/) explains how to do that without making the line stand out. Avoid shrinking the whole page below a size that is comfortable to read, since many recruiters skim on a phone.

## Making a tailored version for each application
A good use of quick editing is a tailored copy for each job. Keep one clean master and make a copy for every application, changing the headline, the first bullet or two and the skills that match the posting. Name each file clearly so you know what went where.

Do not edit the only copy. Save as first, every time, and keep the master in a folder you never send from.

> **Common mistakes**
> - Editing the only copy of the resume instead of using Save as first.
> - Typing a new text box over the old line instead of editing the line itself, which leaves the old text underneath.
> - Using a white rectangle to hide an old phone number. The number is still in the file.
> - Changing the visible link text and forgetting that the link target is separate.
> - Writing dates in two different styles on one page.
> - Making a line so long that it runs past the margin and gets cut off when printed.
> - Forgetting to read the finished page from top to bottom.

## Scanned or photographed resumes
If your only copy is a scan or a phone photo, there is no text to click. Run OCR first: press Ctrl+Shift+O, choose the language (English and Hebrew are bundled and work offline) and wait for the text to be recognised. Then press **E** and edit as above. Compare each recognised word with the image, especially names, numbers and email addresses, where a recognition error looks like a normal word. The step-by-step version is in [how to OCR a scanned PDF for free](/articles/how-to-ocr-a-scanned-pdf-for-free/).

## What Gold PDF does and does not do
Gold PDF is a free, offline PDF editor for Windows. Its Edit text tool (**E**) changes existing lines and redraws them at the same position, size and colour, rebuilding the edited page when you save, and nothing is uploaded, which matters for a document full of personal details. OCR (Ctrl+Shift+O) makes scanned resumes editable, Redact (**R**) removes details for good, and you can add a password with AES-256 before you email the file. It does not reflow text, so it will not push the rest of the page down when you add a line, and it does not rewrite your resume for you. Gold AI is optional and works only with your own key. It runs on Windows only.
