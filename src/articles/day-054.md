To delete pages from a PDF for free, open the file, select the pages you do not want, delete them and save a new copy. On Windows you can do this offline in Gold PDF, or in your browser with the free delete-pages tool on pdf.gold, where the file is not uploaded.

## Quick steps
1. Open the PDF in Gold PDF with Ctrl+O, then press Ctrl+Shift+S and save a copy, so your original stays as it is.
2. Open the Thumbnails panel and click the first page you want to remove. Hold Ctrl to add more pages, or Shift to select a range.
3. Check that only the pages you meant are highlighted. Read the page numbers, not just the pictures.
4. Use the Delete page command.
5. Scroll through the result and confirm the page count is what you expected.
6. Press Ctrl+S, then reopen the saved file and look at the first and last pages once more.

## Which method to use
There is no single best way. It depends on where you are and how many pages you need to remove.

| Situation | Best option | Why |
|---|---|---|
| One or two pages, on your Windows PC | Gold PDF thumbnails | You see each page before it goes |
| A long list such as 3, 7-9, 15 | The browser tool on pdf.gold | You type the numbers once |
| Not on Windows | The browser tool on pdf.gold | It works in the browser |
| You want to keep only a few pages | Extract pages instead | Quicker than deleting the rest |
| You want separate files | Split instead | One file per range |

If you are deleting most of the file, it is usually faster to keep the pages you want than to remove the ones you do not. The free [extract pages tool](/tools/extract-pdf-pages/) does that in one step.

## How to delete pages with a page range
In the browser tool you type the pages to remove, and the format matters. Use commas to separate pages and a hyphen for a run of pages:

- `4` removes page 4 only.
- `3, 7-9` removes page 3 and pages 7, 8 and 9.
- `2-` removes everything from page 2 to the end, which leaves only page 1.

Page numbers mean the position in the file, not the number printed on the page. If a report has a cover and a contents page, the page printed "1" may be the third page of the file. Count from the thumbnails, not from the footers. The tool needs at least one page to remain, so you cannot delete every page.

Open the [delete PDF pages tool](/tools/delete-pdf-pages/), drop in the file, type the list and download the result. The original is never changed, and the remaining pages keep their order.

## Typical pages people remove
Most deletions fall into a few groups, and each has its own risk:

- **A blank page from a scan.** The scanner sometimes inserts a page for the back of a single-sided sheet. Delete it, then check the numbering is still right.
- **A cover sheet or fax header.** Safe to remove, but make sure the next page carries the title or date you need.
- **An attachment you should not share.** Remove the whole page rather than covering it. See below.
- **Duplicate pages.** A scan can include the same page twice. Compare the content before you delete, because a revised page can look the same at thumbnail size.
- **Old versions of a form page.** Keep the one with the signature and delete the unsigned copy only if you are sure which is which.

## Deleting a page versus hiding what is on it
Deleting a page takes it out of the new file, so it is a reliable way to make sure an unneeded page is not sent. It does not protect what is on the pages that remain. A name on page 2 is still on page 2 after you delete page 5.

When a page contains a few private details among material you need, deleting it may lose too much, and a plain cover will not hide the text. Mark the details with the Redact tool instead, and save so the page is rebuilt without them. The steps are in [how to redact a PDF so it cannot be undone](/articles/how-to-redact-a-pdf-so-it-cannot-be-undone/). A good habit for sensitive files is to delete whole pages that are not needed first, then redact what is left, then check the result with the tests in [how to check if a PDF redaction is secure](/articles/how-to-check-if-a-pdf-redaction-is-secure/).

## What to check after you save
A short review stops the usual surprises:

- **Page count.** Compare the new total with the original total minus the pages you removed.
- **First and last pages.** Make sure the cover or signature page you needed is still there.
- **Links and contents.** A table of contents or bookmarks may point to pages that no longer exist, or now land on the wrong page. Test two or three.
- **Page numbers printed on the pages.** They will not renumber themselves, so a gap in the printed numbers is normal and may need a note.
- **File size.** It usually drops. If it does not, the pages you removed were small, which is fine.
- **Search.** Look for a word that was only on a deleted page. It should no longer be found in the saved copy.

> **Common mistakes**
> - Deleting by the number printed on the page instead of its position in the file.
> - Overwriting the only copy, then finding that you deleted the wrong page.
> - Forgetting that a deleted page still exists in the original file you keep.
> - Assuming that deleting one page hid the same details repeated on other pages.
> - Typing a range with a typo, for example 7-9 instead of 7-8, and losing a page you needed.
> - Not checking the saved file before sending it.

## Free options and their limits
Some free tools put a watermark on the result, limit the number of pages or ask for an account. Others upload your file to a server, which matters if the pages contain contracts, medical letters or IDs. Before you pick a tool, ask three questions: does the file leave my computer, is there a limit on size or pages, and does the output carry a mark? If a tool fails any of them for a sensitive document, use an offline option. For a sense of what a private, offline approach means in practice, see [how to edit a PDF offline on Windows](/articles/how-to-edit-a-pdf-offline-on-windows/).

## What Gold PDF does and does not do
Gold PDF is a free, offline PDF editor for Windows 10 and 11, with no account, watermark or page limit. You can select pages in the Thumbnails panel, delete them and extract pages into a new file, then save with Ctrl+S or Save as. Deleting a page removes it from the saved copy only; it does not hide details on other pages, and a Whiteout cover never removes text. Redaction (R) rebuilds the pages you mark when you save. Gold PDF does not run on Mac or Linux, so use the browser tool there. Optional Gold AI features work only with your own key and are not needed to delete pages.
