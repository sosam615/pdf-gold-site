To change the font size in a PDF, open it in a PDF editor, select the line of text and set a new size, then check that it still fits its space. In Gold PDF you press **E**, click the line, change the size in the ribbon and press Ctrl+S, all offline and free on Windows.

## Quick steps
1. Open the PDF in Gold PDF with Ctrl+O, or drag it onto the window.
2. Use **Save as** (Ctrl+Shift+S) so the original stays untouched.
3. Press **E** for Edit text and click the line you want to resize.
4. Set the new size in the ribbon and watch the line change on the page.
5. Zoom to 150% or more and check the spacing around it.
6. Press Ctrl+S to save the new version.

## Why font size in a PDF behaves differently from a word processor
In a word processor, text is a flowing stream. Make one word bigger and everything after it moves along, and the lines wrap again by themselves. A PDF does not work like that. Each line is placed at a fixed position on the page, usually with its own width, and nothing knows about the lines beside it.

That has two practical effects. First, a bigger size makes the line wider and taller, but its neighbours stay where they are, so it can run into them. Second, a smaller size leaves a gap that nothing fills, so a heading shrunk by two points can look lost in its own space.

Knowing this makes the job easier. You are not reformatting a document; you are adjusting one line, then checking the space around it. The rest of this guide is about doing that without making the page look patched.

## How to change the font size of one line in a PDF
Resizing a single line is the common case: a title that is a little too large, a footnote that is hard to read, a price that was printed smaller than the others.

- **Select the exact line.** In Edit text mode, click the line. Lines are the unit you work with, so a two-line label is two separate lines.
- **Change the size in small steps.** Moving from 10 to 11 points is usually safe. Jumping from 10 to 16 almost always collides with something.
- **Keep the left edge.** The line normally keeps its starting position, so text grows to the right. For right-aligned numbers such as prices in a column, check that the right edge still lines up with the other numbers.
- **Look at the line above and below.** Zoom in and compare the gap with the gaps elsewhere on the page. Uneven spacing is what makes an edit noticeable.

If the line was wrong as well as the wrong size, fix both in one pass. ## Choosing a size that matches the rest of the page
When you change a size, the goal is usually to match something else on the page. A rough guide for ordinary documents:

| Kind of text | Typical size | Notes |
|---|---|---|
| Body text in letters and reports | 10 to 12 points | Compare with a neighbouring paragraph |
| Footnotes and small print | 7 to 9 points | Below about 7 becomes hard to read when printed |
| Subheadings | 13 to 16 points | Usually bold and a step above body text |
| Main titles | 18 to 28 points | Depends on the design of the page |
| Form answers | Match the printed labels | Aim for the same height as the label text |

These are habits, not rules, and every document is different. The reliable method is comparison: type or resize, then look at the new line beside a similar printed line at 150% or 200% zoom. If you cannot tell which is which, the size is right.

## Making text bigger so it is easier to read
Sometimes the real aim is readability, not editing. If a PDF is simply too small on screen, you do not need to change the file at all. Zoom in, or fit the page to the window width. Changing the stored size is only worth it when the document will be printed or shared and the small text is a problem for the people who will read it.

For a printed copy, a few points of extra size on footnotes or form labels can make a real difference. Remember, though, that the page has only so much room. If the extra size forces text into the next line, consider shortening the wording slightly rather than shrinking everything else to compensate.

## When changing the size is not the right fix
A few situations look like font-size problems but are better handled differently.

- **The text is a scanned picture.** If the page was scanned, the letters are part of an image and have no size to change. Run **Recognize text** (Ctrl+Shift+O) first, which creates searchable text on top of the scan. See [how to OCR a scanned PDF for free](/articles/how-to-ocr-a-scanned-pdf-for-free/). Whether you can then restyle it depends on the page; often it is better to leave the scan alone and add new text next to it.
- **You want to resize a whole document.** A PDF is a fixed layout. If you need every page reflowed at a larger size, the right route is to change the original file and export a new PDF.
- **You are adding words rather than changing them.** For new text, press **T**, set the size in the ribbon before you type and click where it should go. [How to add text to a PDF document](/articles/how-to-add-text-to-a-pdf-document/) explains matching size and colour.
- **The old text should disappear.** Resizing or covering text does not remove it from the file. For private information, use the Redact tool (R) instead.

## A worked example: fixing small print on a rental notice
Someone has a one-page notice from a landlord, exported as a PDF. The main text is a comfortable 11 points, but a paragraph of conditions at the foot of the page is printed at 7 points, and a relative who will read the printed copy cannot manage it.

1. They open the file and use Save as to create "notice-large-print.pdf".
2. They press **E** and click the first line of the conditions paragraph.
3. They raise the size from 7 to 9 points and look at the result at 200% zoom. The line is now wider, and it still fits inside the page margins.
4. They repeat the change for the remaining lines of the paragraph, one by one, using the same size each time so the paragraph looks even.
5. On the fourth line the text now touches the page edge, so they shorten one phrase slightly, replacing a long word with a shorter one that means the same thing.
6. They check the gap between the paragraph and the signature line, which has tightened a little but is still clear.
7. They press Ctrl+S, print one page as a test and keep the original file for their records.

Nothing left the computer, and the original file is still there if they want to compare it.

## What Gold PDF does and does not do
Gold PDF is a free PDF editor for Windows 10 and 11 that works offline, with no account, watermark or page limit. You can edit existing lines with Edit text (E), add new text with the Text tool (T), fill forms, place signatures from a reusable library, recognise scanned pages (Ctrl+Shift+O, English and Hebrew bundled), redact with pages rebuilt on save (R) and add AES-256 passwords. > **Common mistakes**
> - Raising the size by several points at once and not checking what the larger line now touches.
> - Resizing only some lines of a paragraph, so the paragraph looks uneven.
> - Trying to resize a scanned page without recognising the text first.
> - Overwriting the only copy instead of using Save as first.
> - Hiding private information by changing or covering text instead of redacting it.
