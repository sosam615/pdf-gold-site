To redact names from a court document PDF, you have to remove each name from the file itself, not just cover it, because a black box drawn over a name still leaves the words searchable and copyable underneath. In Gold PDF, search for every form of the name, press **R** to mark each one, and save: the pages with redactions are rebuilt so the names no longer exist in the document.

## Quick steps
1. Check the court's rules and any order in the case to confirm **which** names must be redacted and **how** (full removal, initials, or a pseudonym).
2. Open the filing in Gold PDF and use **Save as** to keep a private, unredacted original.
3. If the filing is scanned, press **Ctrl+Shift+O** to run OCR so the pages can be searched.
4. Press **Ctrl+F** and search for every variation of each name. Write down every page with a hit.
5. Read the caption, headers, footers, signature blocks, exhibits and footnotes by eye.
6. Press **R** and drag a redaction box over each mention.
7. If the rules call for initials, press **E** on the line and type the initials where the name was.
8. Press **Ctrl+S**, close the file, reopen it, and search again for every variation. Nothing should be found.

## Why names in court filings leak
Court documents are public in many places, and filings are often uploaded to electronic court systems where anyone with access can download them. When a name is hidden badly, it does not stay hidden for long: the file is copied, indexed and passed around, and there is no way to pull it back.

Most leaks come from the same few causes:

- **Covering instead of removing.** A black rectangle, a black highlight or a white shape hides the name on screen, but the text is still in the file. Selecting the area and pasting it into Notepad shows the name. This is explained in [does drawing a black box redact a PDF](/articles/does-drawing-a-black-box-redact-a-pdf/).
- **Missing a mention.** A name redacted in the body of a brief but left in a footnote, an exhibit list or a page header.
- **Missing a form of the name.** "Smith" removed, but "Smith's", "Ms. S." or a first name used later in the text left in.
- **Hidden places.** Bookmarks, document properties, file names and comments that mention the person.

## Where names hide in a court document
A court filing is not one block of text. It is usually a stack of different parts, each of which can mention the same person.

| Part of the filing | What to look for |
|---|---|
| Caption | Party names in the case title, sometimes repeated in a short form on every page |
| Running headers and footers | Short case title, file name or page labels with a surname |
| Body text | Full names, surnames, first names, possessives, titles like "Mr." or "Dr." |
| Footnotes | Names in citations, quoted messages and background details |
| Signature blocks | Names of declarants and witnesses, sometimes with addresses |
| Certificate of service | Names and addresses of people served |
| Exhibits | Emails, letters, screenshots, photos and scanned forms with names inside images |
| Bookmarks and properties | Bookmark titles, the document title and the author field |

Exhibits deserve the most time. They are often scans or screenshots, so a name in an email header or a letterhead is part of an image and may not show up in a search unless you run OCR first. For scanned pages, the full routine is in [how to redact a scanned PDF document](/articles/how-to-redact-a-scanned-pdf-document/).

## How to find every mention of a name
Search is your best helper, but only if you search for more than the full name. For a person named Daniel James Okafor, a thorough search list might look like this:

- The full name: **Daniel Okafor**, and with the middle name.
- The surname alone: **Okafor**, which also catches **Okafor's** and **Okafors**.
- The first name alone: **Daniel**, plus nicknames such as **Dan** or **Danny** if they appear in messages.
- Initials: **D.O.**, **DO** and **D. J. O.**
- Titles: **Mr. Okafor**, **Dr. Okafor**.
- Related details that identify the person just as well: an email address, a username, a phone number, a street address or a case-specific nickname.

Search for each item with **Ctrl+F**, step through every result, and note the page numbers. On scanned pages, OCR can misread letters, so also search for parts of the name, such as the first four letters of a surname.

Then do a visual pass at 150% to 200% zoom. Read the caption, every header and footer, every footnote, and every exhibit page from top to bottom. Search finds the words you thought of; the visual pass finds the ones you did not.

## How to redact the names
Press **R** to open the Redact tool and drag a box over each mention. Make the box slightly larger than the word so the tops of tall letters and the tails of letters like g and y are covered. If a name sits inside a table cell or an exhibit stamp, it is often safer to cover the whole cell.

When you press **Ctrl+S**, Gold PDF rebuilds each page that contains a redaction. The page is rendered as a high-resolution image with the black bars burned in, and the remaining words are added back as an invisible text layer so the page stays searchable. The redacted names are not in that layer. Pages without redactions are left as they were.

### When the rules call for initials
Some courts and orders do not want a blank bar; they want a minor or a protected person identified by initials or a pseudonym, such as "J.D." or "Witness A". In that case:

1. Redact the full name with **R** as usual.
2. Press **E**, click the line and type the initials or pseudonym where the name was.
3. Use the same initials everywhere, so the reader can follow who is who.

Editing text with **E** also rebuilds the page on save, so the original name does not survive under the new wording. Even so, check the saved file: search for the old name and confirm it is gone.

> **Common mistakes**
> - Using Whiteout, a shape or a black highlight. These only cover the name; it can still be copied or searched.
> - Redacting the body but forgetting the caption, footnotes, certificate of service or exhibits.
> - Searching only for the full name and missing surnames, first names, initials and possessives.
> - Leaving a name in the bookmarks, the document title or the file name itself.
> - Filing the unredacted original by mistake. Name your files clearly, such as "REDACTED" and "UNREDACTED - DO NOT FILE".
> - Mixing initials and full names for the same person in different parts of the filing.

## Check the file before you file it
Never trust how the redaction looks. A court filing is hard to take back once it is on the public docket, so test the saved copy every time:

1. **Reopen** the redacted file from disk, not from the window you edited it in.
2. **Search** for every item on your search list. There should be no results.
3. **Copy** across each black bar and paste into Notepad. Nothing from under the bar should appear.
4. **Zoom in** on each bar to make sure no edge of a letter is visible.
5. **Check properties and bookmarks** for any name. The steps are in [how to remove metadata from a PDF before sharing](/articles/how-to-remove-metadata-from-a-pdf-before-sharing/).
6. **Check the file name.** "Okafor_motion_final.pdf" defeats the whole exercise.

For a longer checklist, see [how to check if a PDF redaction is secure](/articles/how-to-check-if-a-pdf-redaction-is-secure/).

## A note on court rules
This article is about the mechanics of removing names from a PDF, not legal advice. Rules on what must be redacted differ between countries, states, courts and case types, and a judge can order more or less than the general rules require. Some courts also expect a redacted public version and a separate unredacted version filed under seal. If you are not sure what applies, check the court's local rules, the clerk's guidance, or ask the lawyer handling the case.

## What Gold PDF does and does not do
Gold PDF is a free, offline PDF editor for Windows. Its Redact tool (**R**) removes the content under each box when you save, by rebuilding only the pages that contain redactions, and it can run OCR on scanned exhibits (**Ctrl+Shift+O**, English and Hebrew bundled) so you can search them. Everything happens on your own computer, so a sealed or sensitive filing is never uploaded. It does not know which names your court requires you to remove, and it does not detect names automatically: finding every mention is your job, with search and a careful read. It does not file anything with a court or connect to e-filing systems. It runs on Windows only, not on Mac, Linux or phones. For a short overview of the tool, see [Redact a PDF](/redact-pdf/).

## A routine for every filing
Confirm the rules, Save as, OCR any scans, search every form of every name, read the caption, footnotes and exhibits by eye, redact with generous boxes, add initials where required, save, reopen and test. Then check the properties and the file name before you upload. The few extra minutes are small compared with a name that ends up on a public docket.
