To correct a typo in a PDF, open the file in an editor that can change existing text, click the line with the mistake, retype it and save. In Gold PDF you press **E** for Edit text, click the line, type the corrected version and press Ctrl+S; the old spelling is removed from the saved page, and you never need the original Word file.

## Quick steps
1. Open the PDF in Gold PDF (Ctrl+O, or drag it onto the window).
2. Use **Save as** (Ctrl+Shift+S) to make a copy, so the original stays untouched.
3. Press Ctrl+F and search for the misspelled word to find every place it appears.
4. Press **E**. Dotted boxes appear around each line of text.
5. Click the line with the typo, retype the whole line correctly and press Enter.
6. Repeat for each occurrence, then press Ctrl+S.
7. Reopen the saved file and search for the old spelling. There should be no results.

## Why typos in PDFs feel hard to fix
A PDF is built to look the same everywhere, not to be rewritten. When you export a document from a word processor, the text is placed on the page as positioned runs of characters, often split into separate pieces per line or even per word. There are no paragraphs in the usual sense, and nothing tells the page to reflow when a word gets longer.

That is why many people's first instinct is to go back to the source file, fix the typo there and export again. That works when you have the source. Often you do not: the file came from a colleague, a client, a print shop or an old project folder, or it was made by a system that only produces PDFs. Correcting the PDF directly is then the quickest route, and for a single wrong letter it is usually cleaner than rebuilding anything.

## How to correct a typo in a PDF line by line
Gold PDF's Edit text tool works on whole lines. When you press **E**, each line of text on the page gets a dotted outline. Clicking one opens it for editing with the current words already filled in. You change what needs changing, press Enter, and the line is redrawn at the same position, size and colour.

A few habits make the correction invisible:

- **Retype the full line, not just the word.** The line is replaced as a unit, so read every word on it before you press Enter. It is easy to fix "recieve" and accidentally drop a comma two words later.
- **Keep the length close to the original.** Most typos are one or two characters, so this is rarely a problem. If a correction makes the line noticeably longer, check that it does not run past the margin or into a column next to it.
- **Zoom to 150% or more.** At normal zoom a line that sits a fraction too high is hard to see. Zoomed in, you can compare it with the lines above and below.
- **Watch for words split across lines.** If a hyphenated word was broken at the end of a line, the typo may be on one line and the rest of the word on the next. Edit both lines.

For a longer look at what the tool can and cannot change, see [how to edit text in a PDF for free](/articles/how-to-edit-text-in-a-pdf-for-free/).

## Which kind of typo, which fix
Not every mistake is a misspelled word. The table below covers the corrections people make most often and the tool that suits each.

| Mistake | How to fix it | What to check afterwards |
|---|---|---|
| Misspelled word in a sentence | Edit text (E), retype the line | Punctuation on the same line |
| Wrong digit in a phone number, date or reference | Edit text (E) | Search for the old number to catch repeats |
| Misspelled name of a person or company | Ctrl+F for every occurrence, then Edit text on each | Headers, footers and signature blocks |
| Wrong amount in a table | Edit text on the figure's line | Totals and subtotals that depend on it |
| Missing word that makes the line too long | Shorten the line, add the rest with the Text tool (T) | Spacing between the two lines |
| Typo on a scanned page | Recognize text (Ctrl+Shift+O), then Edit text | Recognised digits and letters near the fix |

Names deserve extra care. A misspelled client name might appear in the title, the greeting, the body and a footer on every page. Search finds each copy; fixing only the one you noticed first is the most common leftover. Numbers are similar, and [how to change a price in a PDF](/articles/how-to-change-a-price-in-a-pdf/) goes through keeping related figures consistent.

## Correcting a typo in a scanned PDF
A scanned page is a picture of text, so there is nothing to click until the words are recognised. Press **Recognize text** (Ctrl+Shift+O) and Gold PDF reads the page on your computer, with English and Hebrew bundled, so nothing is uploaded. Once recognition finishes, the page has lines you can open with Edit text just like a normal PDF.

Two cautions apply. First, check the letters around your fix: on a weak scan, OCR can read "rn" as "m" or "1" as "l", and you do not want to introduce a new error while fixing an old one. Second, the corrected line is drawn as new text over the page, so on a grainy or tinted scan it can look slightly cleaner than its neighbours. For a single word on a document you are sending by email this is rarely noticeable. If the page will be printed and compared side by side with the original, look at it at full size first. For background on recognition, see [how to make a scanned PDF searchable](/articles/how-to-make-a-scanned-pdf-searchable/).

## Correcting versus covering
Some tools offer a white box you can draw over a word, then type on top. That looks like a correction on screen, but the misspelled word is still in the file underneath. Anyone who searches, copies the line or opens the file in another program can find it. For a cosmetic fix on a document only you will see, that might not matter. For anything you send out, it can be embarrassing: a search for the correct spelling fails, while the wrong one still turns up.

Edit text replaces the line instead. When you save, Gold PDF rebuilds the edited page, so the old spelling is gone from the text layer and the new one is searchable. The difference between covering and removing is explained in more detail in [what is the difference between redacting and whiteout](/articles/what-is-the-difference-between-redacting-and-whiteout/).

## A worked example: a misspelled name on a certificate
A training coordinator has a batch of course certificates exported as PDFs from a booking system. One reads "Jonathon Mills" instead of "Jonathan Mills", and the system will not let them regenerate it until next week.

1. They open the certificate in Gold PDF and use Save as to make "certificate-mills-corrected.pdf".
2. Ctrl+F for "Jonathon" shows two results: the large name in the middle of the page and a small line at the bottom that reads "Issued to Jonathon Mills, ref 20417".
3. They press **E**, click the large name line, type "Jonathan Mills" and press Enter. The name keeps its size and colour.
4. They click the bottom line and retype it in full, checking the reference number while they are there.
5. At 200% zoom they compare the name with the lines around it; it sits on the same baseline.
6. Ctrl+S saves the file. After reopening, a search for "Jonathon" finds nothing, and a search for "Jonathan" finds both lines.

The whole correction takes a couple of minutes, and the certificate can be sent the same day.

## What Gold PDF does and does not do
Gold PDF is a free Windows editor for Windows 10 and 11 that works offline, with no account, watermark or page limit. Edit text (E) changes existing lines at the same position, size and colour, the Text tool (T) adds new text anywhere, and edited pages are rebuilt on save. OCR is built in for scanned pages. It does not reflow paragraphs the way a word processor does, so a correction that adds several words may need you to rebalance the surrounding lines by hand. It does not edit rotated text until you rotate the page back, it does not run on Mac or Linux, and it does not check spelling for you: read the corrected line before you save. If the document has many errors, regenerating it from the source file may still be the better choice.

> **Common mistakes**
> - Fixing the first occurrence of a misspelled name and missing the others in headers or footers.
> - Retyping only part of a line and dropping a word or punctuation mark.
> - Covering a typo with a white box, leaving the wrong spelling searchable in the file.
> - Correcting a scanned page without running OCR first.
> - Overwriting the only copy instead of using Save as.
