To redact a PDF for a Freedom of Information request, decide exactly which details are exempt, remove them with a tool that deletes the content underneath, and release only the saved copy. In Gold PDF, open a copy, press **R**, cover each exempt detail, press Ctrl+S, and then search the saved file to prove nothing survives.

## Quick steps
1. Keep the original file safe and untouched. Open it in Gold PDF and use **Save as** to create a release copy.
2. Read the document once and list every exempt detail: names, addresses, phone numbers, email addresses, account numbers, third-party information.
3. Press Ctrl+F and search for each item so you find repeats in headers, footers and footnotes.
4. Press **R** and drag a box over each detail. Slightly oversize the box.
5. Press Ctrl+S. Pages with redactions are rebuilt without the covered content.
6. Reopen the saved file, search for every redacted term, copy across each black bar into Notepad, and check the document properties.
7. Write a short schedule of redactions: page, what kind of detail, and the reason.

## What a Freedom of Information release asks of you
Freedom of Information, or public records, schemes generally start from the idea that a document should be released, with only specific details withheld. The rules differ between countries, states and organisations, and this guide is not legal advice. What does not differ is the technical risk: if a withheld detail is still hiding inside the file you publish, the release has failed, and you cannot call it back once it is out.

That is why the method matters as much as the decision about what to cover. Two jobs are involved. The first is a judgement: which details fall under an exemption. The second is a technical job: making sure the details you chose are truly gone from the file. A PDF editor can only help with the second. Your legal or information-governance team should own the first.

## How to redact a PDF for a Freedom of Information request
Work on a copy from the first minute. Open the original, choose **Save as**, and give the copy a name such as "request-2026-014-release.pdf". The original stays in your records as proof of what was held, and the release copy is the only file that ever leaves the building.

Read the whole document before covering anything. It is easy to redact a name on page two and forget the same name in the sign-off on page nine. Make a simple list as you read, grouping by type, because exemptions are usually applied by category:

| Category | Typical examples | Where it hides |
|---|---|---|
| Personal data of third parties | names, home addresses, phone numbers | letters, signature blocks, headers |
| Financial identifiers | account and card numbers | tables, attachments, footers |
| Contact details | email addresses | email threads, links, "cc" lines |
| Commercially sensitive text | prices, supplier terms | contract schedules, spreadsheets pasted as images |
| Security details | passwords, door codes, system names | appendices, screenshots |

Then search. Press Ctrl+F in Gold PDF and enter each name, number and domain from your list. Step through every result with Enter and place a box as you go. Also search for common variations, such as a surname written in capitals, a number with spaces, or a first name used alone.

## Marking and saving the redactions
With the Redact tool active (press **R**), drag a rectangle over each detail. Make it a little larger than the text so that no letter edge peeks out. If you misplace a box, press Ctrl+Z and draw it again. When everything is marked, press Ctrl+S. Gold PDF rebuilds each page that has a redaction as a sharp image with the black bars burned in, keeps the remaining words as an invisible text layer so the page is still searchable, and clears the title and author. Pages with no redactions stay as they were.

The difference between this and a drawn rectangle is the whole point of the exercise. A shape sitting on top of text hides it from the eye only; the words remain in the file and anyone can select, copy or search them. The reasons are laid out in [does drawing a black box redact a PDF](/articles/does-drawing-a-black-box-redact-a-pdf/), and the plain Whiteout tool in Gold PDF only covers, so it should never be used for a release.

## A worked example: a complaint file
Imagine a council receives a request for the complaint file about a noisy event. The file is a 14-page PDF made of an email thread, a scanned letter, and a short report. The reviewer decides to withhold the complainant's name, home address and phone number, and the names of two staff members below manager level, while releasing everything else.

The reviewer opens "complaint-file.pdf" and uses Save as to create the release copy. A search for the complainant's surname finds nine results across pages 1, 3, 4, 7 and 12. A search for the street name finds four more, two of them inside a signature block. Searching for the start of the phone numbers finds those. All of these get a redaction box. The scanned letter on page 8 has no text layer, so the reviewer presses Ctrl+Shift+O to run text recognition, searches again, and finds two further mentions. After pressing Ctrl+S, the reviewer reopens the file, searches for the surname, the street and both phone numbers, and gets no results. Copying across each bar and pasting into Notepad gives an empty clipboard. The reviewer then writes the schedule: "pp. 1, 3, 4, 7, 8, 12: personal data of a third party".

## Scanned pages, images and screenshots
Many records arrive as scans or photographs of letters. Because a scan is only a picture, search finds nothing in it until you run recognition. Gold PDF's text recognition (Ctrl+Shift+O) works offline, with English and Hebrew bundled, and it is useful for locating what to cover. It is not perfect on small, skewed or faint type, so also read each scanned page by eye. The rebuild on save replaces the covered pixels, so the picture of the detail is not left behind. For the full method see [how to redact a scanned PDF document](/articles/how-to-redact-a-scanned-pdf-document/).

## Metadata and other hidden places
A release can fail without any visible mistake. Author names, document titles, comments and older revisions can carry exactly the detail you removed from the pages. Redacted saves clear the title and author, but check the properties yourself and read [how to remove metadata from a PDF before sharing](/articles/how-to-remove-metadata-from-a-pdf-before-sharing/) for the rest. If the same name appears on dozens of pages, the approach in [how to redact multiple pages in a PDF at once](/articles/how-to-redact-multiple-pages-in-a-pdf-at-once/) saves time.

## Checking the file before release
Never judge by what the screen shows. On the saved copy:

1. Search for every redacted name, number and domain.
2. Select across each black bar, copy, and paste into a plain text editor.
3. Open the document properties and confirm nothing identifying remains.
4. Read each page at 100% for details you missed, especially in margins and footers.
5. Have a second person check a sample. A fresh pair of eyes finds what the author's eyes skip.

If anything survives, go back to the original, add the missing box, and save a new release copy. The broader checks are collected in [how to check if a PDF redaction is secure](/articles/how-to-check-if-a-pdf-redaction-is-secure/).

## What Gold PDF does and does not do
Gold PDF is a free Windows application that works offline, needs no account and does not upload your documents. Its Redact tool removes the covered content from the pages it rebuilds. It does not decide what is exempt, it does not find sensitive information on its own, and it does not write your refusal notice or explain your reasons to the requester. You choose what to cover, then you verify the result. It is available for Windows only.

> **Common mistakes**
> - Releasing the original file, or overwriting it, instead of working on a Save as copy.
> - Using a rectangle or whiteout and calling it redaction.
> - Covering a name on one page but not the same name in a header or footnote.
> - Skipping the search of the saved file before sending it out.
> - Forgetting document properties, comments and scanned pages.
