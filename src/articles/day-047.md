To add text to a PDF document, open it in a PDF editor, choose the text tool, click where the words should go and type. In Gold PDF you press **T**, click the spot on the page, type your text, adjust its size and colour in the ribbon and press Ctrl+S to save, all offline on Windows.

## Quick steps
1. Open the PDF in Gold PDF with Ctrl+O, or drag it onto the window.
2. Use **Save as** (Ctrl+Shift+S) to keep the original untouched.
3. Press **T** for the Text tool.
4. Set the font size and colour in the ribbon so the new text matches the page.
5. Click exactly where the text should start and type.
6. Zoom in to check the alignment, then press Ctrl+S to save.

## Adding text versus editing text in a PDF
People often say "add text" when they mean one of two different jobs, and the tool you need depends on which one it is.

| What you want | Example | Tool in Gold PDF |
|---|---|---|
| Put new words where there were none | A date beside "Date:", a note in the margin, an answer on a flat form | Text tool (**T**) |
| Change words that are already printed | A wrong name, an old price, a typo | Edit text (**E**) |
| Type into boxes the form already provides | Name, address and tick boxes on a fillable form | Click the form fields |
| Put a mark or initials on the page | A signature or initials at the foot of each page | Signatures library |

If the words are already on the page and are wrong, adding new text on top creates two layers that can drift apart, and the old words are still in the file. Use Edit text for that; [how to edit text in a PDF for free](/articles/how-to-edit-text-in-a-pdf-for-free/) shows the method. The rest of this article is about the first row: putting new words on a page.

## How to add text to a PDF document so it looks like it belongs
New text that is the wrong size or sits slightly off the line is the main reason added text looks pasted on. A few habits fix most of it.

**Match the size first.** Before you type, look at the printed text around the spot. Body text in letters and forms is usually between 9 and 12 points. Set a size in the ribbon, type a word, and compare it with its neighbours at 150% or 200% zoom. If it is clearly larger or smaller, change the size and try again; it is quicker than judging by eye at normal zoom.

**Match the colour.** Most documents use black or a very dark grey. Pure black on a page printed in dark grey can stand out, and the reverse is true too. For handwritten-looking forms, a dark blue can be a deliberate choice, but keep it consistent across the whole document.

**Line up with the baseline.** The baseline is the invisible line the letters sit on. Click slightly above a printed rule or beside the label so your letters sit on the same line as the label's letters. Zooming in makes this much easier.

**Keep it short per line.** The Text tool places text where you click; it does not reflow a paragraph around it. If you need two lines, place them as two lines, one under the other, with the same left edge.

## Adding text to a flat or scanned form
Many forms arrive as flat PDFs: the boxes and lines are printed, but clicking them does nothing. You can tell quickly. Open the form in Gold PDF and look for the soft blue highlight that marks real fields. If clicking a box puts a cursor in it, it is fillable and you can follow [how to fill out a PDF form for free](/articles/how-to-fill-out-a-pdf-form-for-free/). If nothing is highlighted, the page is flat and the Text tool is the right choice.

On a flat form:

- Work through it top to bottom so you do not miss a line.
- Use one size for every answer, and one for any small notes.
- For tick boxes, type a capital "X" in the box at a size that fits inside it.
- For dates and amounts, write them exactly the way the form asks, such as DD/MM/YYYY.

A scanned form is a picture of a page. You can still type on it with the Text tool, because the text is placed on top of the image. If you also want to search the original printed words, or copy them, run **Recognize text** (Ctrl+Shift+O) first; English and Hebrew recognition are bundled. The details are in [how to OCR a scanned PDF for free](/articles/how-to-ocr-a-scanned-pdf-for-free/).

## A worked example: completing a flat application form
Someone receives a two-page membership application as a flat PDF from a local club. There are labels and printed lines but no fields, and the club wants it back by email with a signature.

1. They open the file and use Save as to create "membership-completed.pdf".
2. They press **T**, set the size to 10 points and the colour to black, and click just above the line after "Full name". They type their name.
3. Still in the Text tool, they click after "Address", type the first line, then click again directly below for the second line, keeping the same left edge.
4. Beside "Date of birth" they type the date in the format the form shows.
5. For "Membership type", they type an "X" in the "Family" box, making the size small enough that it sits inside the square.
6. On page two there is a blank box for "Anything else we should know". They write two short lines instead of one long one, because the tool does not wrap a paragraph.
7. They place their saved signature from the signatures library on the signature line and add the date with the Text tool next to it.
8. At 200% zoom they check each answer sits on its line, then press Ctrl+S.

The whole job happens on their own PC; the form never goes to a website before it goes to the club.

## Adding notes, labels and reference numbers
Text is not only for forms. Common reasons to add words to an existing PDF include:

- **Reference numbers** on an invoice or a letter before forwarding it.
- **Short notes** for a colleague, such as "see page 4" in a margin.
- **Labels** on a plan or diagram, like room names on a floor plan.
- **Corrections to a printed handout** when the original source file is lost.

For each of these, keep added text visually separate from the original where it helps the reader: a different colour for notes makes it obvious what was added later, while labels on a diagram usually look best in the same colour as the rest.

If what you are adding is meant to replace something that should not be seen, adding text over it is not enough. Covering words with new text or a white box leaves the old words in the file. For anything private, use the Redact tool (R) instead; see [what is the difference between redacting and whiteout](/articles/what-is-the-difference-between-redacting-and-whiteout/).

## What Gold PDF does and does not do
Gold PDF is a free PDF editor for Windows 10 and 11 that works offline, with no account, watermark or page limit. You can add new text anywhere with the Text tool (T), change existing lines with Edit text (E), fill fillable forms, place signatures from a reusable library, recognise scanned pages (Ctrl+Shift+O, English and Hebrew bundled), redact with pages rebuilt on save (R) and add AES-256 passwords. The interface is available in 30 languages. It does not reflow paragraphs like a word processor, so long passages are better added as several short lines or written in the original source document. It does not run on Mac, Linux or phones, and the plain Whiteout tool only covers content rather than removing it.

> **Common mistakes**
> - Typing new text over wrong words instead of using Edit text, which leaves the old words in the file.
> - Guessing the size at normal zoom, so added text is visibly bigger or smaller than the print.
> - Typing one long line into a small box and expecting it to wrap.
> - Overwriting the only copy instead of using Save as first.
> - Using added text or a white box to hide private information instead of redacting it.
