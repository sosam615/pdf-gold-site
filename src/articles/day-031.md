Yes, someone can recover redacted text from a PDF when the text was only covered, for example by a black rectangle, a highlight set to black or white Whiteout, because the original words are still stored in the file. If the text was genuinely removed and the page was rebuilt, as Gold PDF does when you press **R** and save, there is nothing underneath the bar to recover.

## Quick steps
1. Open the redacted PDF you received or produced and make a copy to test on.
2. Press **Ctrl+F** and search for a word you know was hidden, or part of it.
3. Drag-select across a black bar, press Ctrl+C and paste into Notepad.
4. Try clicking the bar. If it moves or can be deleted, it is only a shape.
5. Open the document properties and look at title, author and subject.
6. If any test returns hidden content, redo the redaction properly: press **R** in Gold PDF, drag over each item, save with Ctrl+S, then repeat these tests.

## How redacted text gets recovered from a PDF
A PDF page is not a flat picture. It is a set of instructions: draw this text here, in this font; draw this image there; draw this rectangle on top. When someone "redacts" by drawing a black box, they only add one more instruction at the end. The text instruction underneath is untouched. Every viewer draws the box last, so the page looks correct, but anything that reads text rather than looks at pixels still finds the words.

That is why recovery is usually embarrassingly easy. The common methods are:

- **Copy and paste.** Select the text across the bar and paste it elsewhere. The hidden words come out in full.
- **Search.** Type the hidden name in the search box. The viewer jumps to it and highlights it under the bar.
- **Delete the shape.** Open the file in any editor, click the black box and press Delete.
- **Text extraction.** Free tools that convert a PDF to plain text ignore shapes entirely and print everything.
- **Accessibility readers.** Screen readers speak the text layer, so they read the "redacted" words aloud.

None of these needs special software or expertise. If a careful reader can do it in a minute, so can anyone who receives your file. A fuller walkthrough of this trap is in [does drawing a black box redact a PDF](/articles/does-drawing-a-black-box-redact-a-pdf/).

## Less obvious ways hidden content survives
Covering text is the classic failure, but there are a few quieter ones worth knowing about.

| Where it hides | What happens | How to rule it out |
|---|---|---|
| Text under a shape | Words remain in the page content | Copy across the bar, search for the item |
| Earlier saved versions | Some programs append changes, leaving older content in the file | Use a tool that writes a clean, rebuilt file on save |
| Metadata | Title, author, subject or keywords can repeat a name | Check document properties after saving |
| Bookmarks and comments | Outline entries or notes may quote the removed text | Read the bookmarks panel and comments list |
| Scanned image plus OCR layer | Covering the picture leaves the invisible OCR text, or vice versa | Rebuild the page so image and text are both cleaned |
| File name | "Smith-J-ID-12345.pdf" gives it away | Rename before sending |

The scanned case catches people out. A scan run through OCR has two copies of every word: the picture you see and an invisible text layer on top of it. Covering only the picture leaves the searchable text, and deleting only the text leaves the visible letters. A proper redaction treats both together.

Metadata is a separate problem with its own fix, covered in [how to remove metadata from a PDF before sharing](/articles/how-to-remove-metadata-from-a-pdf-before-sharing/).

## Can the length of a black bar give a word away?
Occasionally, yes. If a document uses a known font and a bar sits exactly over one short word, the width of that bar limits which words could fit. Combined with context, such as "Dear ____," in a letter whose recipient list is small, a reader can sometimes narrow a name down to a few candidates. This is a guessing game rather than true recovery, and it only works for short items in predictable places, but it is easy to make harder:

- Draw each box a little wider than the text, not a tight fit.
- Cover a whole field or line where the length of the value itself is sensitive.
- Redact the label too if "Patient name" next to a short bar says more than you want.

The goal is that the bar shows only that something was removed, not how long it was.

## How to make sure your redacted text cannot be recovered
True redaction removes the content from the file rather than hiding it. In Gold PDF that means using the Redact tool, not a shape or Whiteout:

1. Open the PDF and use Save as (**Ctrl+Shift+S**) to work on a copy. Keep the original somewhere private.
2. If any page is a scan or photo, press **Ctrl+Shift+O** to run OCR so you can search it. English and Hebrew recognition is bundled.
3. Press **R** and drag a box over each item, slightly larger than the text.
4. Press **Ctrl+S**. Every page with a redaction is rebuilt: it becomes a high-resolution image with the black bars burned in, the remaining words are restored as an invisible searchable layer, and the removed words are not included. Document metadata is cleared at the same time.
5. Close the file, reopen it and run the tests from the quick steps above.

Plain Whiteout in Gold PDF only covers, just like a white rectangle, so do not use it for anything confidential. The difference is explained in [what is the difference between redacting and whiteout](/articles/what-is-the-difference-between-redacting-and-whiteout/).

## Testing a PDF someone else redacted
You may also be on the receiving end, for example checking a document before you forward it, or checking a vendor's work. The same tests apply, and they are harmless: they only read the file.

- **Search** for a name or number you know was meant to be removed.
- **Copy** across each bar into Notepad.
- **Click** each bar to see whether it is a movable object.
- **Read** the bookmarks, comments and properties.

If you discover that a file you received still contains hidden text, do not forward it. Tell the sender so they can fix it at the source, and redact your own copy properly before sharing it any further. The full checklist is in [how to check if a PDF redaction is secure](/articles/how-to-check-if-a-pdf-redaction-is-secure/).

## A short example
A small business owner sends a supplier a copy of an invoice dispute. They want the supplier to see the amounts but not a customer's name and phone number, so they draw two black rectangles in a free viewer and save. The supplier's clerk, filing the document, copies the reference line into a spreadsheet. The paste includes the customer's full name, because it sat in the same line under the box.

Done properly, the owner opens the invoice in Gold PDF, saves a copy, presses **R**, drags over the name and the phone number, and presses Ctrl+S. When the clerk copies the same line, the paste stops where the bar begins and continues after it. The name is not there because the rebuilt page no longer contains it.

> **Common mistakes**
> - Drawing a black rectangle or a black highlight and calling it redaction.
> - Using Whiteout on confidential text. It only covers.
> - Testing the document on screen instead of reopening the saved file.
> - Redacting the visible page but forgetting bookmarks, comments or the file name.
> - Tight boxes over short names in letters, which hint at the length of the word.

## What Gold PDF does and does not do here
Gold PDF is a free PDF editor for Windows that works offline, so the file you redact never leaves your computer. Its Redact tool (**R**) removes the marked content when you save by rebuilding each affected page, and it clears document metadata in the same save. It does not decide for you what is sensitive, it has no one-click command that finds and redacts every match, and it cannot fix copies of the document that have already been sent. It also cannot make a black box drawn in another program safe; for that you need to redact the original again. For the overview of the tool, see [Redact a PDF](/redact-pdf/).
