To reorder pages in a PDF, open the file, show the page thumbnails, drag each page to its new position and save a copy. On Windows you can do this offline in Gold PDF, so a confidential file does not have to be uploaded anywhere.

## Quick steps
1. Open the PDF in Gold PDF with Ctrl+O, then press Ctrl+Shift+S and save a copy, so your original order stays as it is.
2. Open the Thumbnails panel on the left, so every page is visible as a small picture.
3. Click the page you want to move, hold the mouse button and drag it to the gap where it belongs.
4. Release, and check that the thumbnail now sits between the pages you intended.
5. Repeat for each page that is out of place, working from the front of the file to the back.
6. Scroll through the whole document at full size and read the page order, not just the pictures.
7. Press Ctrl+S, then reopen the saved file and look at the first and last pages once more.

## Plan the order before you move anything
A reorder goes wrong most often because the final order was never written down. Spend a minute with the thumbnails and decide where every page ends up. A short list is enough: "7 to the front, 12 after 3, 9 and 10 swap". If you only have one or two pages to move, you can skip this, but for a file of twenty pages or more it saves a lot of dragging back and forth.

| Situation | Best approach | Why |
|---|---|---|
| One page in the wrong place | Drag that thumbnail | A single move is quick and easy to see |
| A scanned stack that came out upside down in order | Drag the pages in blocks, or build a new file from the pages in the right order | Moving in blocks needs fewer steps than moving one by one |
| Two files that need to be interleaved | Merge first, then reorder | One file is easier to arrange than two |
| You want only some pages, in a new order | Extract the pages, then arrange the copy | Your original stays complete |
| Pages need turning as well | Rotate, then reorder | See [how to rotate one page in a PDF](/articles/how-to-rotate-one-page-in-a-pdf/) |

If the pages come from two sources, the free [merge PDF tool](/tools/merge-pdf/) on pdf.gold joins them in the browser first. Then you can reorder the combined file as a single document.

## How to reorder pages in a PDF by dragging thumbnails
Dragging is the most direct method, because you see every page while you move it. A few habits make it more reliable:

- **Zoom the thumbnails so you can tell pages apart.** If they look alike, such as pages of a form, scroll through at full size first and note something that identifies each page, such as a heading or a date.
- **Drop into the gap, not onto a page.** The target is the space between two thumbnails. Watch where the marker appears before you release.
- **Move one page, then look.** After each drop, confirm the result before you start the next move. A wrong move is easy to undo with Ctrl+Z right away, but harder to spot an hour later.
- **Work in a copy.** Keep the original file untouched so you can always return to the starting order.

For long files, move whole blocks one page at a time, starting with the first block. When a file is a mix of sections, such as a cover, a summary, three chapters and two appendices, it can be quicker to build the new order from the front: put page one in place, then page two, and so on, until the end matches your list.

## What can break after you move pages
Pages are not isolated. Several things inside a PDF depend on their position, and a reorder can leave them out of step.

- **Printed page numbers.** A number in a footer is part of the page, so it travels with it. After a move you may see "7, 2, 3, 4, 5, 6". If it matters, edit the numbers or leave them off.
- **A table of contents with typed numbers.** If the contents lists "Section 3 .... 12" as plain text, it does not update itself. Change the text, or tell the reader the order was revised.
- **Cross-references in the text.** Phrases such as "see the table on page 9" refer to the old position. Search for the word "page" and review each hit.
- **Bookmarks and links.** Links inside the file normally follow the page they point to. A link that jumps to a page by number may not. Click a few of them.
- **Forms and signatures.** Moving a signed page does not break the signature on that page, but a document that has been digitally signed as a whole may report a change. Reorder before anyone signs, not after.
- **Headers that show a section name.** If each section has its own header, a page moved into another section will show the wrong one.

A quick way to catch most of these is to read the first line of every page in the new order and ask whether the story still makes sense.

## Typical reasons people reorder pages
Most reorders fall into a handful of cases, and each has its own trap:

- **A scan that came out in the wrong order.** A sheet feeder may reverse a stack. Check whether the whole file is backwards, because that is a block move and not a dozen separate ones.
- **An appendix that belongs at the end.** Easy to move, but check that the contents page agrees.
- **A page that was added late.** For example, a signed page that arrived after the rest. Put it in its place and keep a note of the change.
- **A report where the summary should come first.** Move the summary to the front and check the page references in the text.
- **Merged files in the wrong sequence.** If you joined three files and the second went first, move the blocks and verify the joins between them.

If you also need to remove pages that should not be part of the file, do that before you arrange the rest, as described in [how to delete pages from a PDF for free](/articles/how-to-delete-pages-from-a-pdf-for-free/). A shorter file is easier to reorder.

## What to check after you save
A short review prevents the usual surprises:

- **Page count.** It should be the same as before. A reorder moves pages and does not add or remove any.
- **First and last pages.** Make sure the page you meant to put at the front is there.
- **Every page, in order.** Scroll through at a size where you can read each heading.
- **Links and contents.** Click two or three entries and see where they land.
- **Search.** Look for a word that appears on one page only and confirm that it is where you expect.
- **File name.** If you saved a copy, use a name that shows it is the revised order, for example "report-reordered.pdf".

> **Common mistakes**
> - Reordering the only copy of the file and losing the original sequence.
> - Dragging a page onto another page instead of into the gap between two pages.
> - Forgetting that page numbers printed on the pages do not change.
> - Leaving a typed table of contents that still shows the old numbers.
> - Not looking at the saved file before sending it.
> - Moving pages in a file that is already signed as a whole.

## Reordering a file that contains private details
Moving pages does not hide anything. A name or account number on page 4 is still on page 4 when it sits at the front of the file instead. If a document is going to someone who should not see everything, plan the order of work: delete the pages that are not needed, redact the details on the pages that remain, reorder if you must, and test the saved copy. The redaction steps are in [how to redact a PDF so it cannot be undone](/articles/how-to-redact-a-pdf-so-it-cannot-be-undone/). Doing the pages first and the redaction after also means fewer pages to check.

## What Gold PDF does and does not do
Gold PDF is a free, offline PDF editor for Windows 10 and 11, with no account, watermark or page limit. In the Thumbnails panel you can drag pages into a new order, delete or extract pages and rotate them, then save with Ctrl+S or Save as. Reordering changes only the position of whole pages. It does not renumber footers, rewrite a typed table of contents or update text that refers to a page number, so those need a quick edit with the text tool (E) if they matter. A Whiteout cover never removes text, while Redact (R) rebuilds the pages you mark when you save. Gold PDF does not run on Mac or Linux. Optional Gold AI features work only with your own key and are not needed to reorder pages. For the full feature list, see the [free PDF editor for Windows](/free-pdf-editor-windows/).
