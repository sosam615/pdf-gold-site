## Copy-paste listing

- **Name:** Gold PDF
- **Website:** https://pdf.gold
- **Download:** https://pdf.gold/#download
- **Tagline (60):** Free PDF editor for Windows with real redaction and OCR
- **Short (160):** Free offline PDF editor for Windows: edit text, redact for real, OCR scans, fill forms, sign, AES-256 passwords, 30 languages. No account, no watermark.
- **Long:** Gold PDF is a free PDF editor for Windows 10/11. It edits text in place, performs true redaction (content is removed, not covered), runs offline OCR on scanned pages, fills forms, keeps a reusable signature library and encrypts with AES-256. The interface comes in 30 languages, including Hebrew, Arabic and CJK. Optional AI features work with your own API key. Documents stay on your computer. There is also a free in-browser toolkit at https://pdf.gold/tools/ (merge, split, compress, rotate, convert, protect) that never uploads files.
