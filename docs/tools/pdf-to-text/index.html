Extract text from a PDF — copy it or save as TXT

To extract text from a PDF, drop the file here and press Extract text. The words appear below so you can copy them or download a .txt file. It works on PDFs with real text; scanned PDFs need OCR.

Drop your PDF hereor click to choose · stays on your device

    How to do it in 3 steps

    1. Add the PDF. Drag it in or click the box.
    2. Press Extract text. The text is read page by page.
    3. Copy or download. Select all in the box, or save the TXT file.

    About this tool

    Useful for quoting, translating, summarizing with an AI chat, or moving content into Word. If the result is empty, the PDF is probably a scan: open it in the free Gold PDF desktop app and run offline OCR, which supports 100+ languages including Hebrew and Arabic.

    Why use it

    • Private — text never leaves your device.
    • Page markers for long files.
    • Copy or download.
    • No account.

    Questions

    Why is the extracted text empty?

    The PDF is probably a scan (an image). Use OCR in the Gold PDF desktop app.

    Does it keep the layout?

    It keeps reading order and line breaks, not columns or tables.

    Can I extract text from a protected PDF?

    Unlock it first with the Unlock PDF tool.

    Is the PDF uploaded?

    No.
