Add a text watermark to a PDF — free and private

To watermark a PDF, drop it here, type the text (for example CONFIDENTIAL), choose diagonal or horizontal and the opacity, then press Add watermark. It is applied to every page in your browser.

Drop your PDF hereor click to choose · stays on your device

    How to do it in 3 steps

    1. Add the PDF. Drag it in or click the box.
    2. Type your watermark. DRAFT, CONFIDENTIAL, a name or a date.
    3. Download. The text is placed on every page.

    About this tool

    Watermarks mark drafts, protect against casual reuse and label who a copy was prepared for. This web tool supports Latin characters; the free Gold PDF desktop app supports every script, including Hebrew, Arabic and CJK.

    Why use it

    • Private — nothing is uploaded.
    • Adjustable opacity.
    • Diagonal or horizontal.
    • No Gold PDF logo is added.

    Questions

    Can people remove the watermark?

    A determined person with an editor can. For sensitive data use real redaction and password protection.

    Can I watermark with Hebrew or Arabic?

    Not in this web tool; use the Gold PDF desktop app.

    Does it work on every page?

    Yes, all pages.

    Is the original changed?

    No. You download a new file.
