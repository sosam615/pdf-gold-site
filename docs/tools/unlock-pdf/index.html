Remove the password from a PDF (you must know it)

To unlock a PDF, drop the file here, enter its current password and press Unlock PDF. You get a copy that opens without a password. This tool needs the correct password — it cannot crack or bypass one.

Drop your PDF hereor click to choose · stays on your device

    How to do it in 3 steps

    1. Add the protected PDF. Drag it in or click the box.
    2. Enter the password. It is used only inside your browser.
    3. Download the unlocked copy. No password is asked afterwards.

    About this tool

    Use this to simplify files you own and are allowed to share, for example before merging or printing. It does not guess or break passwords.

    Why use it

    • Private — nothing is uploaded.
    • Fast.
    • No watermark.
    • Needs only the file and its password.

    Questions

    Can you unlock a PDF without the password?

    No. This tool does not crack passwords.

    Is it legal?

    Only unlock documents you own or have permission to change.

    Is the password uploaded?

    No.

    Will the layout change?

    No. Only the encryption is removed.
