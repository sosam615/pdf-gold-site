Add page numbers to a PDF — free, private

To add page numbers to a PDF, drop the file here, choose the position and starting number, and press Add page numbers. The numbers are written onto every page in your browser — nothing is uploaded.

Drop your PDF hereor click to choose · stays on your device

    How to do it in 3 steps

    1. Add the PDF. Drag it in or click the box.
    2. Choose position and format. Set the starting number if needed.
    3. Download. Every page now carries its number.

    About this tool

    Page numbers make long contracts, theses and merged bundles easier to reference. Start at any number when a document continues from another file.

    Why use it

    • Six positions and two formats.
    • Private — no upload.
    • No watermark.
    • Page content is not altered.

    Questions

    Can I start numbering from a different number?

    Yes, set "Start at".

    Can I skip the cover page?

    Split the cover off first, number the rest, then merge them again.

    Which font is used?

    Helvetica, 11 pt, dark gray.

    Is my file uploaded?

    No.
