How to Redact Multiple Pages in a PDF at Once

Updated 2026-10-26 · 7 min read · by Gold PDF

To redact multiple pages in a PDF at once, search for every sensitive word first, mark a Redact box over each hit on every page, and then save one time. In Gold PDF, press R, drag over each item on any page, and press Ctrl+S: every page that has a redaction is rebuilt in that single save, and the pages you did not touch stay exactly as they were.

Quick steps

  1. Open the PDF in Gold PDF and press Ctrl+Shift+S to save a working copy. Keep the original private.
  2. If any page is a scan or a photo, press Ctrl+Shift+O to run OCR so its text can be searched.
  3. Write down what must go: names, numbers, addresses, case references, and every way each one is written.
  4. Press Ctrl+F and search for the first item. Step through the hits one by one.
  5. Press R and drag a box over each hit, slightly larger than the text. Move to the next page and continue.
  6. Repeat the search for every other item and every variant.
  7. Press Ctrl+S once. All redacted pages are rebuilt together.
  8. Close the file, reopen it and search again for each item. No results means it worked.

Why "all pages at once" is really "search, mark, save once"

People often hope for a button that finds a word and blacks it out everywhere. That is convenient, but it is also how documents leak: the tool matches the exact text you typed and nothing else. It misses the same name split across two lines, a number written with dashes on one page and spaces on another, and anything inside a picture. Gold PDF takes the slower but safer route. You decide what is removed, page by page, and the single save does the heavy lifting.

The work breaks into three parts, and only the middle one takes time:

  • Finding. Searching for every form of every item, and reading headers, footers, stamps and tables by eye.
  • Marking. Pressing R and dragging. This is a few seconds per item once you know where it is.
  • Saving and testing. One save rebuilds all the marked pages. Then you test the saved copy, not the one on screen.

How to redact the same item on every page

A long document often repeats the same detail in the same place: a case number in the footer, a client name in the header, a reference stamped in a corner. For those, speed comes from rhythm rather than from searching.

  1. Zoom out until three or four pages are visible in a column. Keep the zoom high enough that you can see the item clearly.
  2. Press R and draw a box over the footer on the first visible page.
  3. Scroll a little, and draw the next box at the same height on the next page.
  4. Keep going to the end of the document, then go back to the top and look at each box at normal zoom to check that it fully covers the text.

Page margins are consistent in most documents, so your boxes will line up. If a few pages have a slightly different layout, such as an attached letter or a scanned insert, they need a closer look. Press Ctrl+F on the item afterwards to find any page where the text sits somewhere unexpected.

Redacting different items on different pages

Contracts, medical files, court bundles and HR records usually mix many different items: one page has a signature and an address, another has a table with account numbers, a third has a photo. A simple way to stay organised is to work through the document in passes rather than page by page.

1. NamesFull name, first name alone, surname alone, initials, possessivesCtrl+F each form, redact each hit
2. NumbersAccount, ID, phone, reference, in every formatCtrl+F short pieces such as the last four digits
3. AddressesStreet, house number, postal code, emailCtrl+F each part separately
4. ImagesPhotos, signatures, scanned inserts, logos with namesRead by eye, redact the picture area
5. Headers and footersAnything repeated on every pageDraw a box on each page

Doing one category at a time is easier on the eye than hunting for everything at once, and it lets you tick each pass off a list. A longer example for personal numbers is in how to redact bank account numbers in a PDF, and one for names is in how to redact names from a court document PDF.

What happens when you save

When you press Ctrl+S, Gold PDF rebuilds each page that has at least one redaction. The page becomes a sharp, high-resolution image with the black bars burned in, and the words that remain are restored as an invisible text layer so the page stays searchable. Pages without a redaction are left alone, including their live form fields. The document title, author and other metadata are cleared.

This has two practical consequences for a multi-page job:

  • Time. A save with two pages marked is quick. A save where every page of a long document is marked takes noticeably longer, because each page is rebuilt. Let it finish before you close the window.
  • Size. Rebuilt pages are images with a text layer, so the file can grow. If you only need to redact five pages out of a hundred, the other ninety-five stay small.

If a page has nothing to hide, do not mark it. That keeps the file smaller and keeps those pages as sharp, selectable text.

A worked example: a 12-page tenancy file

Imagine a tenancy bundle you must send to a mortgage broker. It has twelve pages: an agreement, a bank statement, a reference letter and a scan of an ID card. You want the broker to see rent and dates but not your account number, your employer's name or your ID number.

  1. Open the file and save a copy as "tenancy-for-broker.pdf".
  2. Press Ctrl+Shift+O. The ID scan on page 11 is a photo, and OCR makes it searchable.
  3. Search for the last four digits of your account. Hits appear on pages 6, 7 and 8 in the statement header.
  4. Press R and mark all three. Then search for the first four digits and mark any transaction lines that show a full number, which turns out to be one transfer on page 7.
  5. Search for your employer's name. It appears on page 9 in the letterhead and in the signature block, and also on page 12 in a footer you had forgotten about. Mark each one.
  6. Go to page 11. Press R and cover the ID number and the photo.
  7. Press Ctrl+S. Seven pages are rebuilt; pages 1 to 5 and 10 are untouched.
  8. Reopen the copy and search for the account digits, the employer's name and the ID number. There are no results.
  9. Drag across each black bar and paste into Notepad. Nothing comes back.
  10. Check that the file name does not contain your name or ID number before you send it.

The most helpful habit in this example is searching for the employer's name again after the first round. That second search found the footer on page 12.

Checking your work across many pages

With a large file, a single mistake on one page is enough to undo the whole redaction, so the test matters more than the marking. Open the saved copy and:

  • Search for every item and every variant you listed. Step through any hits.
  • Press Ctrl+A on a page you redacted, copy and paste into Notepad. Read what comes back.
  • Scroll through every page at normal zoom and look at each bar edge for partial letters.
  • Open the document properties and confirm that the title, author and subject carry nothing private.

The complete routine is in how to check if a PDF redaction is secure. If you want to be sure why a black rectangle is not enough, see does drawing a black box redact a PDF.

Common mistakes

- Marking the first occurrence of an item and assuming the rest are the same. Search again.- Skipping headers, footers and scanned inserts.- Using Whiteout, a shape or a highlight on some pages "to save time". These only cover.- Saving over the only copy. Use Save as.- Testing the file on screen rather than reopening the saved one.

What Gold PDF does and does not do here

Gold PDF is free, runs on Windows and works offline, so your file never leaves your computer. It lets you place as many redaction boxes as you like across any pages and rebuilds all the marked pages in one save, clearing metadata at the same time. It does not have a one-click "find and redact every match" command, so finding every occurrence is your job, helped by Ctrl+F and OCR. It also cannot know what is sensitive in your particular document. Frequently asked questions

Can I redact several pages of a PDF in one go?

Yes. You can mark redaction boxes on as many pages as you like and then save once. Every page that has at least one redaction is rebuilt in a single save, so you do not need to redact and save page by page.

Is there a single click that redacts a word on every page?

Gold PDF does not have a find-and-redact-all button. The reliable method is to search for the word with Ctrl+F, step through each hit and drag a Redact box over it. That keeps you in control of exactly what is removed.

What if the same text sits in the same place on every page?

Typical examples are a case number in a footer or a name in a header. Zoom out so a whole column of pages is visible, then draw a box at the same spot on each page. Afterwards search the saved file to confirm none was missed.

Will redacting many pages make the file much bigger?

It can. Each redacted page is rebuilt as a high-resolution image with a hidden text layer, so a file where every page is redacted is usually larger than the original. Pages with no redaction stay as they were.

Can I undo a redaction on one page before I save?

Yes. Press Ctrl+Z to remove the last box, or click a box and delete it. Once you save, the original content on that page is gone from the saved file, which is why you should use Save as and keep the unredacted original somewhere private.
