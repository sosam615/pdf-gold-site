How to Rotate One Page in a PDF

Updated 2026-11-21 · 5 min read · by Gold PDF

To rotate one page in a PDF, select only that page in the thumbnail panel, rotate it 90 degrees at a time until it is upright, and save the file. Every other page stays exactly as it was, because rotation is stored per page.

Quick steps

  1. Open the PDF in Gold PDF with Ctrl+O, then use Save as (Ctrl+Shift+S) so your original stays untouched.
  2. Open the page thumbnails and click the one page that is sideways or upside down.
  3. Check that only that thumbnail is selected, not the whole document.
  4. Rotate it clockwise or counter-clockwise until the text reads normally. A page that is upside down needs two turns.
  5. Scroll through the whole file once to confirm the other pages did not change.
  6. Press Ctrl+S, then reopen the saved file and look at the page again.

Why only one page is sideways

Most multi-page PDFs are assembled from different sources. A contract may combine typed pages from a word processor with a scanned signature page, a photographed receipt and a landscape table. Each source has its own natural orientation, and a PDF records that orientation page by page.

When one page is wrong, it is almost always one of three causes. A sheet went into the scanner feeder the other way round. A phone photo was taken while the phone was held sideways, so the picture is stored that way. Or a wide table was deliberately set in landscape and a viewer shows it turned. Because the setting belongs to each page, you can correct one page without changing a neighbour. If you need to fix the text on a scan after turning it, our guide to how to edit text in a scanned PDF explains the recognition step that comes first.

The same idea works for any number of pages, as long as you control the selection:

The most common slip is rotating the whole document when only one page was wrong. If every page turns, press Ctrl+Z, select the single page and try again.

What to check after you save

Rotation is quick, but a few checks catch the problems people discover too late:

  • Look at the page at normal size. Make sure the text reads left to right and the top of the page is at the top.
  • Check the page order. Rotating does not move pages, but selecting thumbnails by mistake can lead to dragging one out of place.
  • Search for a word on that page. On a scan, search only works once the page has text. If it finds nothing, run recognition: see how to make a scanned PDF searchable.
  • Look at the printed result if the file will be printed. A page that looks right on screen can still print sideways if it was rotated in a way the printer driver reads differently, so use print preview first.
  • Reopen the saved file. Confirm the new orientation was stored, rather than only shown in the open window.

Why rotation does not damage the page

Turning a page does not redraw it. The PDF stores a small rotation value for the page, and the viewer applies it when it draws. The letters, images and layout are untouched, so nothing becomes blurrier and the file size barely changes. That is the difference between rotating and, for instance, printing and rescanning. It also means the change is easy to undo: rotate the page back and the file is as it was.

One consequence is worth knowing. A rotated page is still the same page underneath. A sideways scan that you turn upright is a sideways picture with a rotation setting. If you later extract that page, copy its image or open it in a program that ignores the setting, it may appear sideways again. When the page matters, check it in a second viewer before you send it.

Common mistakes

- Rotating the whole document when only one page was wrong.- Forgetting to save and then wondering why the page is sideways on the recipient's computer.- Editing the only copy of an important file instead of using Save as first.- Turning the wrong direction and then rotating three more times instead of pressing Ctrl+Z.- Trying to edit text on a rotated page, then blaming the tool.- Leaving the page-range box in a browser tool empty and rotating every page.

When rotating is not enough

Sometimes the fault is deeper than orientation. A page photographed at a slight angle is not sideways but skewed, and rotation by 90 degrees will not straighten it. A page that is cut off at the edge cannot be repaired by turning it. A badly lit photo stays badly lit. In those cases a better scan is quicker than any fix. If the page is also full of private details that someone else will read, remember that turning it does not hide anything: see how to redact a scanned PDF document for the steps that remove information from the image.

Frequently asked questions

Can I rotate just one page in a PDF?

Yes. Select only that page's thumbnail, rotate it by 90, 180 or 270 degrees and save. The other pages keep the orientation they had.

Is the rotation permanent after I save?

Yes, if you save the file. Rotating a page only changes how it is displayed, so no text or image is redrawn, but the new orientation is stored in the saved PDF.

Why does one scanned page appear sideways?

The page was fed into the scanner the wrong way, or the phone was held at an angle. The picture is stored sideways, so the viewer shows it that way until you rotate the page.

Why can't I edit text on a rotated page?

Gold PDF does not edit text on rotated pages until you rotate them back. Rotate the page upright, edit it, and rotate it again if you need the sideways layout.

Can I rotate a page without installing anything?

Yes. The free in-browser rotate tool on pdf.gold works inside your browser and can limit the rotation to the pages you list. Your file is not uploaded.
