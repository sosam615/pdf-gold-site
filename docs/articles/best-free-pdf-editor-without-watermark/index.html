Watermarks and other "free" catches

  • A logo or text stamped across saved pages.
  • A cap on pages or file size.
  • Needing an account or credit card.
  • Uploading your file to a server.
  • Features locked after a trial.

A quick test before you commit

  1. Edit a one-page sample.
  2. Save it and open the saved file in a different viewer.
  3. Check every page, plus the file size and properties.
  4. Try the feature you actually need (redaction, OCR).
