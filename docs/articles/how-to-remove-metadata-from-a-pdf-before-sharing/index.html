How to Remove Metadata From a PDF Before Sharing

Updated 2026-11-27 · 6 min read · by Gold PDF

To remove metadata from a PDF, clear its hidden title, author, subject, keywords and XMP fields before sharing. In Gold PDF, open the file, choose Protect → Remove metadata and save; the document looks identical but the hidden details are gone.

Quick steps

  1. Open the PDF in Gold PDF.
  2. Open the Protect tab and click Remove metadata.
  3. Save with Ctrl+Shift+S as a new file.
  4. Reopen it and check the document properties.

Why metadata matters

A PDF often remembers who wrote it, what software made it, and when. A contract exported from a word processor may carry an employee's name, an internal project title or a previous file name. When privacy or negotiation matters, clear it.

FieldCan reveal
AuthorPerson's or company's name
TitleInternal project names
Creator / ProducerSoftware and version
DatesWhen the document was created or changed
XMPExtended or older descriptive data

What it does not change

Metadata removal does not edit visible text. If a name appears on the page, redact it. See how to redact a PDF so it cannot be undone.

Where else a PDF hides information

The fields in the table above are only the start. A PDF can carry more than one copy of the same details, and clearing one place does not clear the others.

Metadata is invisible when you read the page, which is exactly why people forget it. Someone who receives your file can open its properties in any viewer and see the author's name and the program that produced the document.

A worked example: sending a quote to a new client

Imagine you wrote a quote in a word processor at work, saved it as a PDF and now want to send it to a client who is comparing suppliers. The file's title is still "Quote draft v3 - lowest we can go", and the author field holds your colleague's full name.

  1. Open the PDF in Gold PDF and press Ctrl+Shift+S to save a copy named "Quote-2026-114.pdf". Your working file stays untouched.
  2. Open the Protect tab and click Remove metadata.
  3. Scroll through the pages and look for comments or sticky notes. Delete any that are internal, such as "check margin with Dan".
  4. Save the copy with Ctrl+S.
  5. Close the file and reopen it. Open the document properties. The title and author should be empty.
  6. Check the file name once more. The new name carries only the quote number.

The page looks identical before and after. The difference is what a curious recipient finds when they look behind it.

Metadata is not the same as redaction

Clearing metadata and redacting are two separate jobs, and a safe share often needs both.

  • Remove metadata clears the hidden information fields. It does not touch what is written on the pages.
  • Redact (R) removes text and images you mark on the page, and Gold PDF also clears metadata when it saves a file with redactions.
  • Edit text (E) changes visible wording, such as replacing a name, but it does not clear metadata by itself.

If your file has visible secrets as well as hidden ones, redact first and read how to check if a PDF redaction is secure before you send it.

What to look for in common documents

Different kinds of files tend to leak different details. The table below lists what is worth a second look before each type of document leaves your hands.

Not every field is sensitive. The program that produced a file rarely matters to anyone. Names, internal titles and dates are the fields that cause trouble, because they can show who worked on a document, what it was really called and how long it sat in a drawer before it was sent.

Make it part of a sharing routine

Metadata is easy to forget because nothing on the page reminds you of it. A short routine that you follow every time is more reliable than remembering to check when a file feels important.

  1. Finish the content first. Edit, redact and sign before you clear metadata. Some programs add details again when they save, so clearing at the end catches everything.
  2. Save a sharing copy. Use Ctrl+Shift+S and give the copy a neutral name, such as a reference number. Keep your working file for yourself.
  3. Clear the hidden fields. Open the Protect tab, click Remove metadata and save.
  4. Look behind the page. Check comments, bookmarks and form fields, as listed in the table above. The wider checklist is in how to remove hidden data from a PDF.
  5. Reopen and read the properties. Close the copy, open it again and look at the document properties. Empty title and author fields mean the step worked.
  6. Send only the checked copy. Attach the file you just reopened, not a different version from your downloads folder.

The routine takes a minute or two. It matters most for files that go outside your organisation, such as offers to clients, documents for a court or a public office, and anything you post online.

When metadata is useful to keep

Clearing metadata is not always the right choice. Inside a team, an accurate title and author help people find files in search and tell versions apart. Some archives and publishing systems read the title field to label a document, so an empty title can make a file harder to find later. Organisations that file documents for records may also have their own rules about what has to stay.

A practical middle way is to keep your internal files as they are and clear metadata only on the copies you send out. If you want a helpful title on a shared file, set a neutral one in your word processor before you export, such as "Quote 2026-114", so the title describes the document rather than its history.

Good sharing habits

  • Remove metadata, then send the saved copy — never the original.
  • Remove hidden comments and form data you do not need.
  • Password protect when emailing: how to password protect a PDF for free.

Common mistakes

- Assuming "Print to PDF" removes everything.- Clearing metadata but leaving a name in the page footer.- Forgetting that file names themselves can leak information.

Frequently asked questions

What metadata does a PDF contain?

Common fields are title, author, subject, keywords, creator application, producer and creation or modification dates, plus optional XMP data.

Does removing metadata change how the PDF looks?

No. It only clears the hidden information fields.

Is metadata removed when I redact?

In Gold PDF, saving a document with redactions also clears metadata automatically.
