How to Remove Metadata From a PDF Before Sharing

Updated 2026-10-18 · 2 min read · by Gold PDF

To remove metadata from a PDF, clear its hidden title, author, subject, keywords and XMP fields before sharing. In Gold PDF, open the file, choose Protect → Remove metadata and save; the document looks identical but the hidden details are gone.

In this guide
  1. Quick steps
  2. Why metadata matters
  3. What it does not change
  4. Good sharing habits

Quick steps

  1. Open the PDF in Gold PDF.
  2. Open the Protect tab and click Remove metadata.
  3. Save with Ctrl+Shift+S as a new file.
  4. Reopen it and check the document properties.

Why metadata matters

A PDF often remembers who wrote it, what software made it, and when. A contract exported from a word processor may carry an employee's name, an internal project title or a previous file name. When privacy or negotiation matters, clear it.

FieldCan reveal
AuthorPerson's or company's name
TitleInternal project names
Creator / ProducerSoftware and version
DatesWhen the document was created or changed
XMPExtended or older descriptive data

What it does not change

Metadata removal does not edit visible text. If a name appears on the page, redact it. See how to redact a PDF so it cannot be undone.

Good sharing habits

  • Remove metadata, then send the saved copy — never the original.
  • Remove hidden comments and form data you do not need.
  • Password protect when emailing: how to password protect a PDF for free.

Common mistakes

- Assuming "Print to PDF" removes everything.- Clearing metadata but leaving a name in the page footer.- Forgetting that file names themselves can leak information.

Frequently asked questions

What metadata does a PDF contain?

Common fields are title, author, subject, keywords, creator application, producer and creation or modification dates, plus optional XMP data.

Does removing metadata change how the PDF looks?

No. It only clears the hidden information fields.

Is metadata removed when I redact?

In Gold PDF, saving a document with redactions also clears metadata automatically.
