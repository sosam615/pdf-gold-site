How to Extract One Page From a PDF

Updated 2026-11-26 · 7 min read · by Gold PDF

To extract one page from a PDF, open the file, go to the page you want and save that page alone as a new PDF. On Windows you can do it free and offline with the Extract page button in Gold PDF, or in your browser with the pdf.gold extract tool, which builds the new file on your device without uploading it.

Quick steps

  1. Open the PDF in Gold PDF with Ctrl+O.
  2. Open the Thumbnails panel and click the page you want, so it becomes the current page.
  3. Check the page number in the toolbar to be sure you are on the right page.
  4. Click Extract page in the page tools.
  5. Choose a folder and a name. Gold PDF suggests the original name with "-page-" and the page number added.
  6. Click Save. A new one-page PDF is written and the original file stays exactly as it was.
  7. Open the new file and check that it shows the right page, the right way up.

Extract one page from a PDF in Gold PDF

Gold PDF extracts the page you are currently looking at. That makes the main step simple, but it also means the most important thing is to be on the right page when you click.

  • Pick the page from the thumbnails. Small thumbnails make similar pages look alike, for example two months of the same bank statement. Click the thumbnail, then look at the large page in the main view before you extract.
  • Use the suggested name or a better one. The suggested name, such as "statement-page-4.pdf", tells you where the page came from. If you are sending it to someone, a name that says what it is, such as "signed-page-contract-2026.pdf", is often more useful.
  • Save the new file somewhere you will find it. The save dialog opens in the usual Windows way, so you can pick the Desktop or a project folder.
  • Repeat for other pages. Each click on Extract page creates one file. To get three single pages, go to each page in turn and extract it.

If you made changes to the document, such as a redaction, edited text or a signature, press Ctrl+S first and reopen the saved file before you extract. That way the page you extract comes from the finished version, and you check one clean file rather than a mix of states.

Extract one page in your browser

The free extract pages tool works on any computer with a modern browser, including Mac and Linux. Drop in the PDF, type the page number to keep, for example 4, and click Extract pages. The new file downloads with only that page in it.

The same box accepts a list, such as 2, 5-7, 12, which puts all those pages into a single new file in the order of the original. The file is processed on the page itself and is not uploaded, so it also suits confidential documents. The original file on your computer is never changed.

Common reasons to pull out a single page

Most single-page extracts fall into a few familiar cases, each with a small trap worth knowing:

  • A signature page. Someone asks for the signed page of a contract only. Check that it belongs to the right version of the contract, and keep the full document as well.
  • One invoice from a bundle. A supplier sends twelve invoices in one PDF. Extract the one you need for an expense claim and name the file after the invoice number.
  • A page of a bank or utility statement. Proof of address often needs one page only. Look at what else is on that page, such as balances or transactions, before you send it.
  • A form page. An office may want only the completed form, not the guidance pages around it. Fill the form first, then extract the page.
  • A page you want as an image. Extract it first, then convert the one-page file with the PDF to JPG tool.

When the page you extract will be joined to something else, for example a signature page added to the end of another file, the steps are in how to merge two PDF files into one.

What to check after you extract a page

Extracting is quick, and a check of the new file takes less than a minute:

  • The right page. Open the new file and read the first and last lines. Similar pages are easy to mix up.
  • One page only. The page count should be 1. If it is more, you used a range by mistake in the browser tool.
  • Orientation. A page that was scanned sideways stays sideways. Turn it with the steps in how to rotate one page in a PDF and save again.
  • Text and links. Text should still be selectable. Links that pointed to other pages of the original file no longer have anywhere to go.
  • Form fields. Fillable fields may not stay fillable in the new file. Fill and check the form before you extract it.
  • File name. Make sure the name does not reveal more than the page does, such as a person's full name or salary.

Extracting a page that contains private details

Extracting a page does not hide anything on it. Every name, number and note on that page goes into the new file, along with any comments attached to it. The usual reason to extract is to share less, so it is worth checking that the page itself is not sharing too much.

If the page holds a detail the recipient should not see, such as an account number on a statement, redact it before you extract. Press R, drag over the detail, save so the page is rebuilt, then extract from the saved file. A plain Whiteout or a drawn box only covers the text, so it can still be copied from the new file. For the full method, see how to redact a PDF so it cannot be undone.

Common mistakes

- Extracting the page next to the one you wanted, because two thumbnails looked alike.- Extracting from an unsaved document instead of the finished, saved version.- Typing a range such as 4-5 in the browser tool when you meant only page 4.- Expecting links and fillable fields to keep working in the one-page file.- Sending a statement page without noticing the balance or other private details on it.- Saving the new file with a name that says more than the page should.

What Gold PDF does and does not do

Gold PDF is a free, offline PDF editor for Windows 10 and 11, with no account, watermark or page limit. The Extract page button saves the page you are viewing as a new one-page PDF and leaves the original file unchanged; to extract several pages, you repeat it for each one, or use the browser tool, which takes a list of pages and puts them in one file. Frequently asked questions

How do I extract one page from a PDF for free?

Open the file in a free editor such as Gold PDF, go to the page, click Extract page and choose where to save. You get a new one-page PDF and the original file is not changed.

Does extracting a page change the original PDF?

No. Extracting copies the page into a new file. The original keeps all its pages, so you can extract as many single pages as you need from it.

Can I extract one page without uploading the PDF?

Yes. A desktop editor does it on your own computer, and the extract pages tool on pdf.gold builds the new file inside your browser, so the document is not sent to a server.

Will the extracted page lose quality?

No. The page is copied as it is, so text stays sharp and selectable and images keep their resolution. A scanned page stays a scan.

How do I extract several pages into one file?

Use the browser tool on pdf.gold and type the page numbers, for example 2, 5-7. If you want each page as its own file, extract them one at a time or use the split tool.
