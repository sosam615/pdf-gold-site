How to Black Out a Social Security Number in a PDF

Updated 2026-10-19 · 6 min read · by Gold PDF

To black out a Social Security number in a PDF, you must delete the digits from the file, not just cover them, because a black box drawn on top leaves the number readable to anyone who copies the text. In Gold PDF, press R for the Redact tool, drag over every copy of the number, and save: each redacted page is rebuilt without the original digits.

Quick steps

  1. Open the PDF in Gold PDF and use Save as first, so you keep a private unredacted copy.
  2. Press Ctrl+F and search for the full number, then the last four digits, then the number written without dashes.
  3. If the file is a scan, press Ctrl+Shift+O to recognize text first, then search again.
  4. Press R and drag a redaction box over each occurrence you found.
  5. Press Ctrl+S to save. Gold PDF rebuilds every page that has a redaction.
  6. Reopen the saved file, search for the number again, and try to copy the blacked-out area. Nothing should come back.

Why a Social Security number needs real redaction

A Social Security number is one of the most useful pieces of information a fraudster can get, because it ties a name to credit files, tax records and benefits. That is exactly why a "visual only" black box is dangerous. A PDF stores the text of a page separately from anything drawn on top of it. A highlighter set to black, a filled rectangle or a sticky shape changes what you see on screen but leaves the digits in the text layer. Anyone who receives the file can press Ctrl+A and paste the page into a text editor, or simply delete the rectangle, and the number is back.

Real redaction works the other way around. It removes the characters, and any image pixels under the box, from the saved file. Gold PDF does this by rebuilding each page that contains a redaction as a high-resolution image with the black bars burned in, then adding the remaining words back as an invisible text layer so the page stays searchable. The digits you covered are not in that text layer, because they were removed before it was written. For the general method, see how to redact a PDF so it cannot be undone.

Where Social Security numbers hide in a PDF

The number you can see on page one is rarely the only copy. Before you redact, go through this list:

Searching for the last four digits alone is the single most useful habit here. It catches partial references, such as "SSN ending 6789," that a full-number search misses.

Full number or last four digits?

Before you black anything out, decide how much of the number the recipient actually needs. Common situations look like this:

  • Court filings. Many courts ask filers to show at most the last four digits of a Social Security number. Check your court's own rules before you file, because they vary.
  • Mortgage, lease or job applications. The organization may need the full number, but the copy you keep in an email thread or share with a third party usually does not.
  • Sharing a document with a lawyer, accountant or family member. If the person does not need the number to do their work, remove all nine digits.
  • Public posting or a records request. Remove the whole number.

If you are keeping the last four, draw the redaction box over only the first five digits and the dashes between them. Zoom to 200% or more so the box edge does not clip or reveal part of a neighboring digit. The visible "XXX-XX-" style is not added automatically; the redacted area simply shows as a solid black bar, which is clear enough for most readers.

Blacking out a number on a scanned form

Tax forms, benefit letters and old HR records are often scans. A scan is a picture of the page, so Ctrl+F finds nothing at first. Press Ctrl+Shift+O to recognize text (English and Hebrew are bundled), then search for the number. OCR can misread digits on faint or skewed scans, so also look over the page with your eyes and search for a few likely misreads, such as a 5 read as an S. Then redact as usual. Because Gold PDF rebuilds the page on save, the pixels under the black bar are replaced, not hidden. For a short overview of the tool, see Redact a PDF.

Common mistakes

- Using the Whiteout or a shape tool. Whiteout only covers the digits; it does not remove them.- Searching only for the number with dashes and missing copies written without them.- Forgetting the second and later pages, headers and footers.- Leaving the number in a filled form field that is not printed large on the page.- Overwriting the only original. Use Save as and keep the unredacted file somewhere private.- Sending the file without reopening it to test the redaction.

How to confirm the number is really gone

Never trust what the screen shows. After saving, close the file, reopen it, and run three tests:

  1. Search. Press Ctrl+F and search for the full number, the last four digits and the dash-free version. You should get no results inside the redacted areas.
  2. Copy. Drag across the black bar, copy, and paste into Notepad. You should get nothing, or only the words around it.
  3. Properties. Check the document's title and author fields. Gold PDF clears these on a redaction save, but it is worth a glance if the file came from someone else.

For a longer checklist, read how to check if a PDF redaction is secure, and for the hidden fields see how to remove metadata from a PDF before sharing.

A short routine to reuse

If you black out Social Security numbers often, for example in HR, payroll or legal work, turn the steps above into a habit: Save as, search three formats, OCR any scans, redact, save, reopen, test. It takes a couple of minutes per document and removes the most common way these numbers leak, which is a black box that only looked like redaction.

Frequently asked questions

Can I just draw a black rectangle over a Social Security number?

No. A drawn rectangle sits on top of the digits, which stay in the file and can be copied, searched or revealed by deleting the shape. Use a real redaction tool that removes the text underneath.

Should I black out the whole number or leave the last four digits?

It depends on who asked for the document. Many forms and courts accept the last four digits, but if no one needs any part of the number, remove all nine digits.

How do I find every place the number appears?

Search the PDF for the full number, then for the last four digits alone, and for the number without dashes. Also check headers, footers, attachments, form fields and scanned pages, which are not searchable until you run OCR.

Does blacking out a number on a scanned PDF work the same way?

Yes, if the tool rebuilds the page. A scan is an image, so the redaction must replace the pixels, not just cover them. Run OCR first so you can search for the number.
