How to Remove Hidden Data From a PDF

Updated 2026-11-01 · 6 min read · by Gold PDF

To remove hidden data from a PDF, delete what you can see should go, mark anything sensitive with a real redaction, save a new copy and then test that copy. In Gold PDF that means pressing R over the sensitive areas, saving under a new name, and checking the properties, search results and copied text of the saved file.

Quick steps

  1. Work on a copy and keep the original somewhere safe.
  2. Open the copy and check the file properties for author, title and other names.
  3. Look through any comments, notes and marked-up text and delete the ones you do not want to share.
  4. Press R and drag over anything that must disappear, on every page.
  5. Press Ctrl+S and save under a new file name.
  6. Reopen the new file and press Ctrl+F for each word or number that should be gone.
  7. Drag across the redaction bars, copy and paste into Notepad to confirm nothing is underneath.
  8. Check the file name itself before you attach it to a message.

What hidden data can a PDF hold?

A PDF is a container, not a picture of a page. Alongside the words you read, it can store several kinds of information that never appear on screen.

Hidden itemWhat it can revealHow it gets there
Document propertiesAuthor, title, subject, keywords, creating programFilled in automatically by the program that made the file
Text under shapesThe exact words a black box was meant to hideDrawing a rectangle instead of redacting
Comments and annotationsReviewers' remarks, sticky notes, highlightsLeft over from a review round
Form field valuesNames, numbers and answers typed earlierA form was filled and then flattened badly or not at all
AttachmentsWhole files embedded inside the PDFAdded by the author or by a scanning workflow
Bookmarks and linksSection titles, internal names, web addressesGenerated from the source document
Cropped contentParts of a page that sit outside the visible areaChanging the page view without removing the content
File nameClient names, case numbers, datesChosen by whoever saved the file

None of these are bugs. They are normal parts of the format, which is exactly why they are easy to forget when you send a file to someone else.

Why covering something is not removing it

The most common source of leaked information is a shape placed over text. The rectangle looks solid, but the words stay in the file and can be selected, copied or found with search. If you only draw over something, anyone who opens the file in another viewer may be able to read it. This is explained in does drawing a black box redact a PDF.

Real removal means the content is gone from the saved file. In Gold PDF, each page that contains a redaction is rebuilt as a high-resolution image with the bars burned in, and the remaining text is restored as an invisible layer so the page still searches and copies. The marked values are not in that layer. For the full method, see how to permanently remove text from a PDF.

Step by step: clearing the usual suspects

Properties and metadata

Open the document properties and read every field. Author names often belong to a person, not a company, and the title may be an old draft name. Gold PDF clears the document's metadata when you save, but you should still reopen the saved file and look, rather than assume. A longer walkthrough is in how to remove metadata from a PDF before sharing.

Comments and review marks

If the file has been through a review, scroll through every page looking for notes, highlights and callouts. Delete the ones that were only for internal use. Marks that cover sensitive wording should become redactions instead, because deleting a note does not remove the sentence it pointed at.

Sensitive words and numbers

Search the document for names, account numbers, addresses and anything else you promised not to share. Mark each hit with the Redact tool. If the document is a scan, run Ctrl+Shift+O first so the words become searchable; otherwise you can only find what you spot by eye. Hand-written notes and low-quality scans may not be recognised correctly, so check the image as well.

Whole pages you do not need

The safest hidden data is the data that is not in the file. If a page is not needed by the recipient, remove the page instead of redacting inside it. A shorter file is also quicker to check.

How to test that the data is really gone

Looking at the page is not a test. Use at least these three checks on the saved copy:

  1. Search. Press Ctrl+F and look for each removed word, name and number. There should be no results.
  2. Copy. Drag across each redaction bar, copy, and paste into Notepad. The paste should be empty.
  3. Properties. Open the properties again and confirm that author, title and other fields are blank or generic.

A fuller checklist is in how to check if a PDF redaction is secure. If any check fails, go back to your working copy, fix it, save a new file and test again. Never trust a file you have not tested.

A short example

A small firm wants to send a signed agreement to a bank. The file's author field shows the name of a junior employee, an old comment from a colleague asks "can we cut the fee?", and a client's account number appears on page four. The sender opens a copy, deletes the comment, presses R over the account number, and saves a new file. Searching for the number finds nothing, copying across the bar gives an empty paste, and the properties no longer show the employee. Only then is the file attached to the email, under a plain name that does not mention the client.

Common situations

  • Sharing a draft for feedback: remove metadata and internal comments, but you may decide to leave the text as it is.
  • Publishing on a website: treat the file as public forever. Remove everything you would not put on a notice board, and check the file name.
  • Sending to a court or authority: follow their rules on redaction first. How to redact names from a court document PDF covers the general approach.
  • Sending a contract: see how to redact a contract before sharing it.

These are general practices, not legal advice. What you are required to remove depends on your role and your local rules.

Common mistakes

- Drawing a rectangle or highlight and assuming the text is gone.- Clearing the properties but leaving the sensitive words in the body.- Forgetting comments and notes from an earlier review round.- Redacting a scan without running OCR, so you cannot search for what you missed.- Sending the working copy, or redacting the only original.- Leaving a revealing file name on a clean file.

Frequently asked questions

What hidden data can a PDF contain?

Document properties such as author and title, comments and annotations, text hidden under shapes, form field values, attachments, bookmarks and sometimes leftovers from earlier versions or the original file name.

Does saving a PDF as a new file remove hidden data?

Not by itself. Many tools keep metadata, comments and covered text when you save, so you need to remove them on purpose and then check the new file.

How do I check a PDF for hidden data?

Look at the file properties, open any comments panel, press Ctrl+F for words that should be gone, and copy across suspicious areas into Notepad to see what is really underneath.
