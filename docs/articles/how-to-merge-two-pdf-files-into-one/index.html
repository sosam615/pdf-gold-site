How to Merge Two PDF Files Into One

Updated 2026-11-24 · 7 min read · by Gold PDF

To merge two PDF files into one, open the first file, add the pages of the second file after it, and save the result as a new copy. On Windows you can do this free and offline in Gold PDF, or in your browser with the pdf.gold merge tool, which joins the files on your device without uploading them.

Quick steps

  1. Open the PDF that should come first in Gold PDF with Ctrl+O.
  2. Press Ctrl+Shift+S and save a copy under a new name, so the original file stays untouched.
  3. Click Merge PDF in the page tools and choose the second file.
  4. Wait a moment while the pages of the second file are added after the last page of the first.
  5. Open the Thumbnails panel and check that the page count equals both files together.
  6. Drag any page that is out of place into its correct position.
  7. Press Ctrl+S, then reopen the saved file and scroll through every join between the two parts.

Both options copy the pages as they are. Nothing is converted to an image, so text stays selectable and searchable, and a scanned page stays a scan.

Get the order right before and after the merge

In Gold PDF the file you have open stays at the front and the merged file goes at the end. That covers the most common case, such as a letter followed by its attachment, a report followed by an appendix, or a signed page added to the end of a contract.

When the order is different, there are two simple approaches:

  • Open the file that belongs first. If the attachment should actually lead, open it instead and merge the letter into it.
  • Merge and then rearrange. If pages from the two files must alternate, for example the front and back sides of a two-sided scan, merge first and then drag the thumbnails into place. The method is described in detail in how to reorder pages in a PDF.

Plan the final order on paper for anything longer than a few pages. A short note such as "pages 1 to 4 of A, then all of B, then page 5 of A" saves a lot of dragging later, and lets you check the result against something written down rather than against memory.

What to check after you merge two PDF files

Merging is quick, but the join between two documents is where small problems appear. These checks take a minute or two:

  • Page count. The total should equal the pages of both files together. If it is lower, the second file may not have been added at all.
  • The join. Look at the last page of the first file and the first page of the second. Make sure nothing was skipped or duplicated.
  • Page size and orientation. Files from different sources can have different page sizes, for example A4 and US Letter, or a landscape table among portrait pages. They are kept as they are. Turn a sideways page with the steps in how to rotate one page in a PDF.
  • Page numbers. Numbers printed in a footer belong to each page, so the second part may start again at 1. Leave them, edit them with the text tool, or add new numbers to the whole file.
  • Bookmarks and links. The outline of the second file may not be carried over, and a table of contents in the first file does not know about the new pages. Click a few links to see where they land.
  • Form fields. Fill and check forms before you merge. Fillable fields from the added file may not stay fillable afterwards, so it is safer to merge a completed form than an empty one.
  • File size. The combined file is roughly the size of both originals. If it is too large to email, the free compress PDF tool can shrink it.

Common reasons to combine two PDFs

Most merges fall into a few familiar cases, each with a small trap worth knowing:

  • A cover letter and a CV. Many application forms accept a single upload only. Put the letter first, and check that both pages use the same paper size so the file prints cleanly.
  • A contract and its signed page. If the signature page arrived as a separate scan, add it to the end and check that it really belongs to this version of the contract.
  • An invoice and its receipts. Expense claims often need one file. Merge the invoice with the scanned receipts, then make sure every receipt is readable at normal zoom.
  • Two halves of a scan. A scanner that stops halfway leaves two files. Merge them, then look closely at the join for a missing or repeated page.
  • A report and an appendix. Merge the appendix at the end, then update any typed contents page that lists page numbers.

If one of the files contains pages that should not be part of the final document, remove them first. The steps are in how to delete pages from a PDF for free.

Merging files that contain private details

Merging does not hide anything. Every name, account number and note in both files is still there, along with whatever comments or hidden text the originals contained. If the combined file is going to someone who should not see everything, the order of work matters: delete the pages that are not needed, merge, redact what remains on the combined file, and test the saved copy before you send it. Redacting once, on the final file, means you only have one document to check.

Working offline also matters for sensitive files. Gold PDF never uploads the documents, and the browser tool on pdf.gold processes them on the page itself. In both cases the files stay on your computer from start to finish.

Common mistakes

- Merging into the only copy of the first file and losing the original.- Opening the wrong file first, so the attachment ends up in front of the letter.- Not checking the join and missing a duplicated or skipped page.- Merging an empty form and expecting its fields to stay fillable.- Forgetting that the second part may still show its own page numbers.- Sending the merged file without scrolling through it once.

What Gold PDF does and does not do

Gold PDF is a free, offline PDF editor for Windows 10 and 11, with no account, watermark or page limit. The Merge PDF button adds all the pages of a second PDF after the last page of the file you have open, and the Thumbnails panel lets you drag pages into a new order, delete, extract or rotate them, and insert blank pages. Each merge adds one file, so for three or more files you repeat it, or use the browser tool, which takes several at once. Merging does not renumber printed page numbers, rebuild a table of contents or guarantee that bookmarks and fillable fields from the added file carry over. After merging you can keep working in the same file: edit text with E, redact with R (redacted pages are rebuilt on save), run OCR on scanned pages with Ctrl+Shift+O, sign, or add an AES-256 password. Gold PDF does not run on Mac or Linux. For the full feature list, see the free PDF editor for Windows.

Frequently asked questions

How do I merge two PDF files into one for free?

Open the first file in a free editor such as Gold PDF, press Merge PDF, choose the second file and save a copy with Save as. The pages of the second file are added after the last page of the first.

Can I merge PDFs without uploading them?

Yes. A desktop editor joins the files on your own computer, and the merge tool on pdf.gold builds the combined file inside your browser, so neither sends the documents to a server.

Which file goes first when I merge?

The file you have open stays at the front and the merged file is added at the end. If you need a different order, merge first and then drag the page thumbnails into place.

Does merging reduce the quality of the pages?

No. Merging copies the existing pages as they are, so text stays sharp and images keep their resolution. The combined file is roughly the size of the two originals together.

Will form fields and bookmarks survive a merge?

Not always. Page content is copied reliably, but bookmarks and fillable fields from the added file may not carry over. Fill and check forms before merging, and test the result.
