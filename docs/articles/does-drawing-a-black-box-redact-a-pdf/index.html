Does Drawing a Black Box Redact a PDF

Updated 2026-10-18 · 2 min read · by Gold PDF

No — drawing a black box does not redact a PDF. A box is a picture sitting on top of the words, and the words are still in the file. Real redaction removes the covered text and image data so that nothing can be selected, copied or recovered.

In this guide
  1. What actually happens under the box
  2. How to redact properly in Gold PDF
  3. Whiteout still has a place

What actually happens under the box

PDF files keep text and graphics as separate objects. A black rectangle is just another graphic. Open the file in a different program, delete the rectangle, or press Ctrl+A and copy, and the words appear. That is why "blacked out" documents have repeatedly exposed names, numbers and settlement amounts.

  3. Search the saved file for the word to confirm.

Whiteout still has a place

Use Whiteout and Edit text for corrections — like fixing a date — when the old value is not a secret. When it is a secret, use Redact. The difference matters: see how to permanently remove text from a PDF.

Common mistakes

- Trusting how the page looks on screen instead of testing the saved file.- Redacting only the visible page while the name stays in the metadata or in a hidden comment.- Emailing the redacted file before searching it.

Frequently asked questions

Can you copy text from under a black box in a PDF?

Yes, if the box is just a drawing. The text beneath is still in the file, so it can be selected, copied or exposed by deleting the shape.

Is highlighting text in black the same as redacting?

No. A black highlight is still a visual layer on top of the text.

What does a real redaction tool do?

It deletes the covered text and image data from the file and clears related metadata, then saves.
