How to Delete Pages From a PDF for Free

Updated 2026-11-22 · 6 min read · by Gold PDF

To delete pages from a PDF for free, open the file, select the pages you do not want, delete them and save a new copy. On Windows you can do this offline in Gold PDF, or in your browser with the free delete-pages tool on pdf.gold, where the file is not uploaded.

Quick steps

  1. Open the PDF in Gold PDF with Ctrl+O, then press Ctrl+Shift+S and save a copy, so your original stays as it is.
  2. Open the Thumbnails panel and click the first page you want to remove. Hold Ctrl to add more pages, or Shift to select a range.
  3. Check that only the pages you meant are highlighted. Read the page numbers, not just the pictures.
  4. Use the Delete page command.
  5. Scroll through the result and confirm the page count is what you expected.
  6. Press Ctrl+S, then reopen the saved file and look at the first and last pages once more.

If you are deleting most of the file, it is usually faster to keep the pages you want than to remove the ones you do not. The free extract pages tool does that in one step.

How to delete pages with a page range

In the browser tool you type the pages to remove, and the format matters. Use commas to separate pages and a hyphen for a run of pages:

  • 4 removes page 4 only.
  • 3, 7-9 removes page 3 and pages 7, 8 and 9.
  • 2- removes everything from page 2 to the end, which leaves only page 1.

Page numbers mean the position in the file, not the number printed on the page. If a report has a cover and a contents page, the page printed "1" may be the third page of the file. Count from the thumbnails, not from the footers. The tool needs at least one page to remain, so you cannot delete every page.

Open the delete PDF pages tool, drop in the file, type the list and download the result. The original is never changed, and the remaining pages keep their order.

Typical pages people remove

Most deletions fall into a few groups, and each has its own risk:

  • A blank page from a scan. The scanner sometimes inserts a page for the back of a single-sided sheet. Delete it, then check the numbering is still right.
  • A cover sheet or fax header. Safe to remove, but make sure the next page carries the title or date you need.
  • An attachment you should not share. Remove the whole page rather than covering it. See below.
  • Duplicate pages. A scan can include the same page twice. Compare the content before you delete, because a revised page can look the same at thumbnail size.
  • Old versions of a form page. Keep the one with the signature and delete the unsigned copy only if you are sure which is which.

Deleting a page versus hiding what is on it

Deleting a page takes it out of the new file, so it is a reliable way to make sure an unneeded page is not sent. It does not protect what is on the pages that remain. A name on page 2 is still on page 2 after you delete page 5.

When a page contains a few private details among material you need, deleting it may lose too much, and a plain cover will not hide the text. Mark the details with the Redact tool instead, and save so the page is rebuilt without them. The steps are in how to redact a PDF so it cannot be undone. A good habit for sensitive files is to delete whole pages that are not needed first, then redact what is left, then check the result with the tests in how to check if a PDF redaction is secure.

What to check after you save

A short review stops the usual surprises:

  • Page count. Compare the new total with the original total minus the pages you removed.
  • First and last pages. Make sure the cover or signature page you needed is still there.
  • Links and contents. A table of contents or bookmarks may point to pages that no longer exist, or now land on the wrong page. Test two or three.
  • Page numbers printed on the pages. They will not renumber themselves, so a gap in the printed numbers is normal and may need a note.
  • File size. It usually drops. If it does not, the pages you removed were small, which is fine.
  • Search. Look for a word that was only on a deleted page. It should no longer be found in the saved copy.

Common mistakes

- Deleting by the number printed on the page instead of its position in the file.- Overwriting the only copy, then finding that you deleted the wrong page.- Forgetting that a deleted page still exists in the original file you keep.- Assuming that deleting one page hid the same details repeated on other pages.- Typing a range with a typo, for example 7-9 instead of 7-8, and losing a page you needed.- Not checking the saved file before sending it.

Free options and their limits

Some free tools put a watermark on the result, limit the number of pages or ask for an account. Others upload your file to a server, which matters if the pages contain contracts, medical letters or IDs. Before you pick a tool, ask three questions: does the file leave my computer, is there a limit on size or pages, and does the output carry a mark? If a tool fails any of them for a sensitive document, use an offline option. For a sense of what a private, offline approach means in practice, see how to edit a PDF offline on Windows.

Frequently asked questions

How do I delete a page from a PDF for free?

Open the file in a free editor such as Gold PDF, select the page and use Delete page, or use the free browser tool on pdf.gold and type the page numbers to remove. Then save a new copy.

Can I delete several pages at once?

Yes. List the pages and ranges, for example 3, 7-9, in the browser tool, or select several thumbnails before deleting. Check the page count afterwards.

Does deleting a page make the PDF smaller?

Usually yes, because the page and the images only it used are not copied into the new file. A text-only page saves very little.

Does deleting a page redact the information on it?

The page is gone from the new file, so what was on it is not in that copy. It does not hide private details on pages you keep; for that, redact them.

Can I undo a deletion after saving?

Not in the saved file. Use Save as so your original stays untouched, or press Ctrl+Z before saving.
