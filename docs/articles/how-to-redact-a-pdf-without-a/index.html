How to Redact a PDF Without A

Updated 2026-11-03 · 5 min read · by Gold PDF

You can redact a PDF without A by using any editor whose Redact tool removes the content instead of covering it. In Gold PDF, press R, drag over what must disappear, and save: each redacted page is rebuilt without the original words, and the program is free to use on Windows with no account.

Quick steps

  1. Open the PDF in Gold PDF (Ctrl+O, or drag the file onto the window).
  2. Use Save as first so the original stays untouched.
  3. Press Ctrl+F and search for every name, number or phrase you plan to hide, so you know where they all are.
  4. Press R and drag a box over each one. Make the box slightly larger than the text.
  5. Press Ctrl+S to save. The pages with redactions are rebuilt.
  6. Reopen the saved file, search again for each term, and try selecting and pasting the area into Notepad. Nothing should come back.

Why people look for a way to redact without A

Redaction is a one-off job for many people: a tenant hiding a salary, a small business sharing a contract, a student submitting a form with an ID number. Paying for a large suite or signing up for a subscription for a single task feels like too much, and some people simply do not want to create an account or send a private file through a website. The good news is that the technique matters more than the brand. What you need is a tool that really deletes the content underneath the bar.

Be careful with the free options you find. Many "free" tools draw a rectangle and nothing more, or they add a watermark, or they ask you to upload the document to their servers. For a confidential file, each of those is a problem. You can compare the main choices in best free PDF redaction tool for Windows.

What real redaction has to do

A PDF stores text, images and drawings as separate objects. If you draw a box, the text object is still there under it. A tool that redacts properly must do three things:

  • Remove or replace the text and image data under the marked area.
  • Remove leftovers such as hidden layers, document properties and orphaned objects.
  • Let you verify the result on the saved file, not just on screen.

The reasons a simple box fails are explained in does drawing a black box redact a PDF.

Redacting in Gold PDF, step by step

Open the file and press R. The cursor changes and you can drag rectangles over text, numbers, logos, signatures or parts of images. Press Ctrl+Z to undo a box that is too big or in the wrong place.

When you press Ctrl+S, Gold PDF rebuilds every page that contains a redaction as a sharp, high-resolution image with the black bars burned in, adds the remaining words back as an invisible text layer so the page stays searchable, and clears the document title and author. Pages without redactions are left exactly as they were, including their form fields.

Because only some pages change, a long contract with one redacted clause stays mostly editable and small. If you want to hide the same item on many pages, search for it first and mark each occurrence; see how to redact multiple pages in a PDF at once.

A worked example: sharing a lease

Imagine a two-page lease that you want to send to a bank, but you must hide your date of birth and your account number. Open "lease.pdf", choose Save as and name the copy "lease-redacted.pdf". Search for the date of birth: it appears on page 1 and in the signature block on page 2. Search for the account number: it appears once in the payment section and again as a reference in the footer. Press R and cover all four spots. Save with Ctrl+S, close the file, and open it again. Search for the date and the account number; neither is found. Select around a black bar and paste into Notepad; the clipboard stays empty. The document is now safe to send, and you can add a password as an extra layer using how to password protect a PDF for free.

Scanned documents and photos

A scan has no text, so there is nothing to search. Run Recognize text with Ctrl+Shift+O (English and Hebrew work offline) so you can find terms, then redact as usual. The rebuild on save also replaces the covered pixels, so the picture underneath is not left behind. The details are in how to redact a scanned PDF document.

Checking your work

Never trust the screen alone. Use this short checklist on the saved copy:

  1. Search for each redacted word, number and variant spelling.
  2. Select across a black bar, copy, and paste into a plain text editor.
  3. Open the file properties and confirm the title and author are empty.
  4. Look at every page at 100% zoom for anything you missed, such as headers, footers and small print.

If something survives, reopen your original, add the missing box, and save a fresh copy.
