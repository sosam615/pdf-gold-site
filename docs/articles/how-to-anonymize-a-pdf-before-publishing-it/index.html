How to Anonymize a PDF Before Publishing It

Updated 2026-11-06 · 7 min read · by Gold PDF

To anonymize a PDF before publishing it, remove every direct identifier (names, contact details, ID numbers), look for indirect clues that still point to one person, and clear the file's metadata. In Gold PDF, search for each identifier, cover it with the Redact tool (R), save so the pages are rebuilt without the original content, and then test the saved copy.

Quick steps

  1. Keep the original safe. Open it in Gold PDF and use Save as to create a copy with a neutral file name.
  2. Read the whole document and list every name, number, address, email, place and unusual detail.
  3. Press Ctrl+F and search for each item, stepping through every result.
  4. Press R and drag a box over each one. Make the box a little larger than the text.
  5. Press Ctrl+S. Pages with redactions are rebuilt and the title and author are cleared.
  6. Reopen the saved copy, search for each removed item, copy across the black bars into Notepad, and open the document properties.
  7. Ask someone who has not seen the original to read it and say whom they think it is about.

What anonymizing a PDF really means

Anonymizing is more than blacking out a name. A document is anonymous only if a reader cannot work out who it is about, even by combining it with other things they know. Removing the obvious identifiers is the first half of the job. The second half is judgement about everything that is left.

Which standard applies to you depends on your country, your field and the reason you are publishing, and this guide is not legal advice. If a regulation or an ethics board governs the document, follow its checklist and let a person responsible for privacy approve the result. A PDF editor can do the technical part: make sure the details you chose to remove are really gone from the file.

Direct and indirect identifiers

Direct identifiers point straight to a person. Indirect identifiers point to them only in combination. Both belong on your list before you open the Redact tool.

TypeExamplesWhere it hides in a PDF
Directfull name, signature, photo, email, phone, home address, ID or account numberletterheads, signature blocks, footers, tables
Indirectjob title, employer, small town, exact date, rare illness, unusual eventquotes, case descriptions, captions, appendices
Technicalauthor and title fields, comments, bookmarks, file namedocument properties and the file system

A quote such as "the only female surgeon at the regional hospital" contains no name, yet it identifies one person to anyone who knows the area. Decide for each indirect clue whether to remove it, generalise it or keep it. You can cover it with a redaction box, or use Edit text (E) to replace it with something more general such as "a hospital doctor". Edit text rebuilds the page on save, so the old wording does not survive underneath the new.

How to anonymize a PDF step by step in Gold PDF

Start from a copy. Press Ctrl+Shift+S and save the working file with a name that says nothing about the people involved, for example "report-public.pdf" rather than "report-smith-clinic.pdf". The original stays in your records.

Then search before you mark. Press Ctrl+F and enter each name from your list. Search for the surname alone, the first name alone, initials and possessive forms such as "Smith's". Search for numbers in different formats: with and without spaces or dashes, and the last four digits by themselves. Step through every result and place a box as you go, because repeated names in headers and footers are the ones that get missed.

With the Redact tool active, drag over each item. If you slip, press Ctrl+Z. When all boxes are placed, press Ctrl+S. Gold PDF rebuilds each page that contains a redaction as a sharp, high-resolution image with the bars burned in, restores the remaining words as an invisible text layer so the page stays searchable, and clears the title and author. Pages without redactions are left as they were.

This is why a drawn rectangle or the Whiteout tool is not enough. Both only cover the words, and the words stay in the file. The reasons are explained in does drawing a black box redact a PDF, and the difference between the two tools is laid out in what is the difference between redacting and whiteout.

A worked example: a staff survey report

Say an HR team has written a 12-page staff survey report and wants to publish it on the company website. It contains free-text comments, a table of results by department, and an appendix with the names of the focus-group volunteers.

  1. The author opens the report and saves a copy called "survey-2026-public.pdf".
  2. A search for the names of the 11 volunteers finds them on page 11, and four of them again in a footnote on page 6. All 15 mentions get a redaction box.
  3. Reading the comments, the author notices "As the only night-shift cleaner in the Leeds office, I feel..." This is an indirect identifier. The author uses Edit text to change it to "As a member of the support staff, I feel..." and saves.
  4. The results table shows one department with two respondents. Two people can easily be recognised, so the author decides to merge that row with another department and redraws the table in the source document before exporting a fresh PDF.
  5. After saving, the author searches for each volunteer's surname and first name, copies across every black bar into Notepad, and finds nothing.
  6. The document properties still show the title "Staff survey draft v3 - Jane Doe". The author clears those fields and saves a new copy.

No redaction tool can fix a table that makes two people identifiable. Small groups, rare categories and exact dates are the usual culprits.

Metadata, comments and the file name

A PDF can carry names in places you do not see on the page. Check these on the saved copy:

  • Document properties: title, author, subject and keywords.
  • Comments and annotations: sticky notes, replies and tracked reviewer names.
  • Bookmarks: headings that quote a person's name.
  • Attachments: embedded files such as the source spreadsheet.
  • The file name and the folder path if you send the file by email.

Saving a redacted document in Gold PDF clears the title and author, but check the rest yourself. The full list and the steps are in how to remove hidden data from a PDF and how to remove metadata from a PDF before sharing.

Anonymizing scans and images

If the PDF is a scan or a phone photo, there is nothing to search until you recognise the text. Press Ctrl+Shift+O to run text recognition, which works offline and includes English and Hebrew. Recognition makes finding names much easier, but it is not perfect on faint, small or crooked print, so also read every scanned page by eye. Photos of people, logos and handwritten notes are identifiers too. You can redact them as regions, and the page rebuild replaces the covered pixels. The method for photos is in how to redact an image inside a PDF, and the scan workflow is in how to redact a scanned PDF document.

Test the result like an outsider

Run these tests on the saved copy, not on the version you were editing:

  1. Search for every name, number and domain you removed.
  2. Press Ctrl+A, copy and paste into a plain text editor. Read it from top to bottom.
  3. Drag across each black bar, copy and paste. The clipboard should be empty.
  4. Zoom to 400% and check the edges of each box for the tops or tails of letters.
  5. Open the properties and the comments panel.
  6. Give the file to a colleague who does not know the case and ask who they think the people are.

If anything is found, go back to the original, correct it and create a fresh public copy. Do not patch a file you have already tested. The wider checklist is in how to check if a PDF redaction is secure.

Common mistakes

- Removing names but leaving job titles, places or dates that identify the same person.- Using a shape, highlight or Whiteout and calling it anonymized.- Forgetting the document title, author, comments and file name.- Anonymizing the page you can see and missing repeats in headers, footers and footnotes.- Publishing without a final read by someone who has not seen the original.

Frequently asked questions

How do I anonymize a PDF before publishing it?

Find every name and identifier with Ctrl+F, cover each with the Redact tool (R) in Gold PDF, save so the pages are rebuilt, then check the document properties and search the saved file.

Is removing the name enough to anonymize a document?

Often not. Job titles, places, dates, rare events and combinations of details can still point to one person, so review the context as well as the names.

Does Gold PDF remove metadata when I anonymize?

Saving a redacted file clears the title and author. Check the properties yourself for anything else, and keep the file name neutral.

Can I anonymize a scanned PDF?

Yes. Run text recognition (Ctrl+Shift+O) so you can search it, redact what you find, and read the pages by eye as well. The pages are rebuilt on save.
