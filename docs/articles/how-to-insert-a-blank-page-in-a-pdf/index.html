How to Insert a Blank Page in a PDF

Updated 2026-11-27 · 7 min read · by Gold PDF

To insert a blank page in a PDF, go to the page that should come just before the new one and add an empty page after it. On Windows you can do it free and offline in Gold PDF: open the Pages tab, click + Blank, then save the file.

Quick steps

  1. Open the PDF in Gold PDF with Ctrl+O.
  2. Open the Thumbnails panel and click the page that should sit just before the blank page.
  3. Check the page number in the toolbar so you know you are on the right page.
  4. Open the Pages tab and click + Blank.
  5. A new empty page appears right after the current page and becomes the current page.
  6. To place it somewhere else, drag its thumbnail to the new position.
  7. Press Ctrl+S to save, or Ctrl+Shift+S to save a copy and keep the original unchanged.

Where to insert a blank page in a PDF

The + Blank button always adds the new page after the page you are viewing. That covers most cases directly, and the Thumbnails panel covers the rest.

Where you want the blank pageWhat to doNote
After a certain page, such as after page 3Go to page 3, click + BlankThe most direct case
At the very endGo to the last page, click + BlankHandy for a notes or signature page
At the very startGo to page 1, click + Blank, then drag the new page in front of page 1Two steps, both quick
Between every chapterRepeat for each chapter, working from the back of the file to the frontPage numbers in front stay the same while you work
Several blank pages in a rowClick + Blank again; each new page goes after the one you are onCount the thumbnails when you are done

Working from the end of the document toward the start is a small habit that saves mistakes. When you insert a page near the front, every page after it moves down by one, so a list of page numbers you wrote down beforehand stops being correct. Inserting from the back leaves the earlier numbers untouched.

Why people add blank pages

A blank page sounds like a small thing, but it solves a few common problems:

  • Double-sided printing. When a document is printed on both sides, each chapter usually should start on a right-hand page. A blank page before a chapter that would otherwise start on the back of a sheet fixes the layout.
  • Room for notes or a signature. An empty page at the end gives space for handwritten notes after printing, or for a signature you add in the editor.
  • A cover or divider page. Insert a blank page at the start and add a title with the text tool, as in how to add text to a PDF document.
  • Matching a required page count. Some print shops and booklet layouts need a page count divisible by four. Blank pages at the end fill the gap.
  • A placeholder. When a page is still missing, such as a scan someone will send later, a blank page holds its place so the numbering of the rest stays right.

Page size and orientation

In Gold PDF the new page takes the width and height of the page you were on when you clicked + Blank. In a document where every page is A4 or Letter, the blank page matches the rest without any extra step.

Mixed documents need a little more care. If you are on a landscape page, the blank page will be landscape too. If you want a portrait blank page in a file that mixes both, go to a portrait page first, insert the blank page there, and drag it to where it belongs. If it still ends up the wrong way round, turn it with the steps in how to rotate one page in a PDF.

Scanned documents sometimes have pages of slightly different sizes, because each sheet was scanned on its own. A blank page copied from one of them can look a fraction larger or smaller than its neighbours on screen. That rarely matters for reading, but for printing it helps to insert the page next to a page of the right size.

Moving a blank page after you insert it

Once the page exists, it behaves like any other page in the Thumbnails panel. Drag it up or down to move it, as described in how to reorder pages in a PDF. If you added one page too many, select it and use Delete page; the full method is in how to delete pages from a PDF for free.

A good order of work is to sort out the pages first and then do everything else. Insert, move and delete pages, save, and only then add text, signatures and comments. That way the content you add sits on pages that are already in their final position, and you check the finished layout once.

Adding content to the blank page

A blank page is useful on its own, but you can also fill it before you save:

  • Text. Use the text tool to add a heading, a note or a short cover letter.
  • A signature. Place a saved signature from the signatures library, for example on a final page labelled "Approved by".
  • A picture. Add a logo or a photo to make a simple cover page.
  • Pages from another file. If what you really need is a page from a different PDF rather than an empty one, merge that file instead, as described in how to merge two PDF files into one, then move the page into place.

What to check before you share the file

A blank page changes the page count, and a quick look over the saved file catches most problems:

  • Total pages. The page count should be the old count plus the pages you added.
  • Position. Scroll through the thumbnails and confirm each blank page sits where you wanted it.
  • Page numbers on the pages. If the original pages carry printed numbers, such as "Page 4 of 10", those numbers do not update. The printed footer and the real page order may now disagree.
  • Table of contents. A contents page that lists page numbers may now be off by one or more for the sections after the new page.
  • Links and bookmarks. Links inside the document that point to a page may need a check after the pages move.
  • Printing. For double-sided printing, print a short test or look at the print preview to be sure each chapter starts on the side you expect.

Common mistakes

- Being on the wrong page when you click **+ Blank**, so the page lands one place off.- Inserting pages from the front of the file to the back, then using page numbers you wrote down earlier.- Forgetting that printed footers such as "Page 4 of 10" do not renumber themselves.- Inserting a landscape blank page into a portrait document by starting from a landscape page.- Saving over the original when you wanted to keep an untouched copy; use Ctrl+Shift+S.- Adding signatures and notes first, then moving pages around afterwards.

Frequently asked questions

How do I insert a blank page in a PDF for free?

Open the file in a free editor such as Gold PDF, go to the page that should come before the new one, open the Pages tab and click + Blank. A blank page is added right after it.

Can I add a blank page at the start of a PDF?

Yes. Insert the blank page after page 1, then drag its thumbnail in front of page 1 in the Thumbnails panel and save.

What size is the blank page?

In Gold PDF the new page takes the same width and height as the page you were on, so it matches the rest of the document.

Can I write on the blank page after I insert it?

Yes. Add text with the text tool, sign it or place a picture on it, then save. The page becomes part of the PDF like any other page.

Does inserting a page change the original file?

Not until you save. Use Save as with Ctrl+Shift+S if you want to keep the original as it was.
